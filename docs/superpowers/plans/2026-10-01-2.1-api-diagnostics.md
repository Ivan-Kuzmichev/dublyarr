# 2.1 «API, диагностика, источники» Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** логи по областям с файлом и экраном «Диагностика», API с токенами только из локальной сети, источники Jackett/JacRed/Torznab, кадры серий на «Сегодня», торренты больше не остаются на паузе.

**Architecture:** логгер pino с полем `area` и уровнями из `app_settings['logging']`; дочерние процессы пишут JSON в stdout, супервизор складывает в `/data/logs` с ротацией. API — один catch-all route `/api/v1/[...path]` поверх роутера `src/lib/api/router.ts`, который зовёт те же функции `src/lib/*`, что server actions (общие куски выносятся из actions в lib). Источники — поле `sources.kind` и диспетчер `searchSource`.

**Tech Stack:** Next.js 16 App Router, TypeScript 6, better-sqlite3 + Drizzle, pino 10, Vitest, Playwright.

**Spec:** `docs/superpowers/specs/2026-10-01-2.1-api-diagnostics-design.md`

## Global Constraints

- Все тексты интерфейса и ошибок API — на русском.
- Секреты (ключи источников, токены API/Telegram/TMDB, пароль qBittorrent) — никогда в логах и ответах API (только «задан / не задан»).
- Удаление файлов — только по правилам хранения; API не обходит подтверждение первого срабатывания.
- Доменная логика — в `src/lib/*`, функции принимают `db` параметром; тесты — на `testDb()` (`tests/unit/helpers.ts`).
- Миграции — `pnpm db:generate` после правки `src/lib/db/schema.ts`; данные переносятся SQL-вставкой в конец сгенерированного файла.
- API: `/api/v1/*`, только `Authorization: Bearer`, по умолчанию выключен, `403` вне локальной сети, «Безопасность» через API недоступна.
- Ротация логов: 10 МБ × 5 файлов (`dublyarr.log`, `.1` … `.4`), `GET /logs` — не больше 2000 строк.
- JacRed: запросы к одному источнику по одному, пауза ≥ 1 с, `429` → одна пауза по `Retry-After` (≤ 10 с).
- Ожидание торрента после `add` — опрос раз в 0,5 с до 15 с; больше 3 перезапусков за час — ошибка «qBittorrent останавливает загрузку».
- Версия — 2.1.0. Каждый коммит заканчивается строками:
  ```
  Co-Authored-By: Claude Opus 5.5 (1M context) <noreply@anthropic.com>
  Claude-Session: https://claude.ai/code/session_01L8VBCG17W738yjV2zJDPu1
  ```

## Review Focus

1. Запрос через Pangolin (`X-Forwarded-For: <внешний>, <частный>`) или поддельный `X-Forwarded-For: 192.168.1.5` от внешнего клиента — должен получить `403` (тест в Task 8).
2. Пауза пользователем или по расписанию не должна сниматься самовосстановлением синхронизации (тесты в Task 5).
3. Повреждённая/незавершённая строка в логе (обрыв при ротации) не должна ломать журнал и `GET /logs` (тест в Task 3).
4. JacRed отдаёт раздачу без magnet или с magnet без btih — пропустить, не уронить поиск (тест в Task 7).
5. Старые источники (полный адрес Torznab Jackett) после миграции продолжают искать без правки (тест в Task 7).

```ts
export const LOG_AREAS = ['qbit', 'search', 'parse', 'downloads', 'import', 'tmdb', 'storage', 'laya', 'telegram', 'worker', 'auth', 'api', 'system'] as const;
export type LogArea = (typeof LOG_AREAS)[number];
export type AreaLevel = 'debug' | 'info' | 'warn' | 'off';
export type LogSettings = { level: 'debug' | 'info' | 'warn'; areas: Partial<Record<LogArea, AreaLevel>> };

let settings: LogSettings = { level: (process.env.LOG_LEVEL as LogSettings['level']) ?? 'info', areas: {} };
let root = createLogger({ level: 'debug', name: process.env.DUBLYARR_PROCESS ?? 'web' });
const children = new Map<LogArea, pino.Logger>();
const levelOf = (a: LogArea) => {
  const l = settings.areas[a] ?? settings.level;
  return l === 'off' ? 'silent' : l;
};

export function logger(area: LogArea): pino.Logger {
  let l = children.get(area);
  if (!l) {
    l = root.child({ area });
    l.level = levelOf(area);
    children.set(area, l);
  }
  return l;
}

export function applyLogSettings(s: LogSettings) {
  settings = s;
  for (const [a, l] of children) l.level = levelOf(a);
}

/** Тесты: писать в свой поток (логгеры областей пересоздаются). */
export function setLogDestination(d: pino.DestinationStream) {
  root = createLogger({ level: 'debug', destination: d, name: 'test' });
  children.clear();
}

export const log = new Proxy({} as pino.Logger, { get: (_t, k) => Reflect.get(logger('system'), k) });
```

`src/lib/log-settings.ts`:
```ts
import type { Db } from './db/client';
import { getSetting, setSetting } from './settings';
import { applyLogSettings, LOG_AREAS, type AreaLevel, type LogSettings } from './log';

const LEVELS = ['debug', 'info', 'warn'] as const;
const AREA_LEVELS: AreaLevel[] = ['debug', 'info', 'warn', 'off'];

export function getLogSettings(db: Db): LogSettings {
  const env = process.env.LOG_LEVEL;
  return getSetting<LogSettings>(db, 'logging') ?? { level: (LEVELS as readonly string[]).includes(env ?? '') ? (env as LogSettings['level']) : 'info', areas: {} };
}

export function saveLogSettings(db: Db, s: LogSettings) {
  setSetting(db, 'logging', s);
  applyLogSettings(s);
}

export function parseLogForm(form: FormData): LogSettings | { error: string } {
  const level = String(form.get('level') ?? 'info');
  if (!(LEVELS as readonly string[]).includes(level)) return { error: 'Неверный уровень' };
  const areas: LogSettings['areas'] = {};
  for (const a of LOG_AREAS) {
    const v = String(form.get(`area.${a}`) ?? 'inherit');
    if (v === 'inherit') continue;
    if (!AREA_LEVELS.includes(v as AreaLevel)) return { error: 'Неверный уровень' };
    areas[a] = v as AreaLevel;
  }
  return { level: level as LogSettings['level'], areas };
}

/** Процессы перечитывают настройку раз в 10 с — смена уровней без перезапуска. */
export function watchLogSettings(db: Db, everyMs = 10_000): () => void {
  const tick = () => {
    try {
      applyLogSettings(getLogSettings(db));
    } catch {
      /* база занята — в следующий раз */
    }
  };
  tick();
  const t = setInterval(tick, everyMs);
  t.unref();
  return () => clearInterval(t);
}
```

```ts
import { appendFileSync, mkdirSync, renameSync, statSync, existsSync, rmSync } from 'node:fs';
import path from 'node:path';

const MB = 1024 * 1024;

export function toJsonLine(line: string, proc: string): string {
  const t = line.trim();
  if (t.startsWith('{') && t.endsWith('}')) return t;
  return JSON.stringify({ level: 30, time: Date.now(), name: proc, area: proc === 'laya' ? 'laya' : 'system', msg: t });
}

/** Один писатель на контейнер (супервизор): ротация по размеру, при ошибке — только stdout. */
export function createLogSink(dir: string, opts: { maxBytes?: number; keep?: number; echo?: (line: string) => void } = {}) {
  const maxBytes = opts.maxBytes ?? 10 * MB;
  const keep = opts.keep ?? 5;
  const echo = opts.echo ?? ((l: string) => process.stdout.write(`${l}\n`));
  const file = path.join(dir, 'dublyarr.log');
  const sink = { error: null as string | null, write };
  let size = 0;
  try {
    mkdirSync(dir, { recursive: true });
    size = existsSync(file) ? statSync(file).size : 0;
  } catch (e) {
    sink.error = `Журнал недоступен: ${e instanceof Error ? e.message : String(e)}`;
  }
  function rotate() {
    rmSync(`${file}.${keep - 1}`, { force: true });
    for (let i = keep - 2; i >= 1; i--) if (existsSync(`${file}.${i}`)) renameSync(`${file}.${i}`, `${file}.${i + 1}`);
    renameSync(file, `${file}.1`);
    size = 0;
  }
  function write(line: string) {
    echo(line);
    if (sink.error) return;
    try {
      if (size > 0 && size + line.length + 1 > maxBytes) rotate();
      appendFileSync(file, `${line}\n`);
      size += Buffer.byteLength(line) + 1;
    } catch (e) {
      sink.error = `Журнал недоступен: ${e instanceof Error ? e.message : String(e)}`;
    }
  }
  return sink;
}
```

`supervisor.ts`: опция `sink?: { write(line: string): void }`. При `sink` — `spawn(..., { stdio: ['ignore', 'pipe', 'pipe'] })`, `readline.createInterface({ input: p.stdout })` и то же для `stderr`, каждая строка → `sink.write(toJsonLine(line, spec.name))`. `logger` по умолчанию при `sink` — пишет `toJsonLine('[supervisor] …', 'supervisor')`. Без `sink` — `stdio: 'inherit'` как сейчас (существующие тесты супервизора не меняются).

`main.ts`: `const sink = createLogSink(path.join(cfg.dataDir, 'logs'));` и `startSupervisor({ children, sink })`; если `sink.error` — `console.warn(sink.error)`.

```ts
import { existsSync, readFileSync } from 'node:fs';
import path from 'node:path';
import { getConfig } from './config';

export type LogLevel = 'debug' | 'info' | 'warn' | 'error';
export type LogLine = { time: number; level: LogLevel; area: string; proc: string; msg: string; data: Record<string, unknown> };
const RANK: Record<LogLevel, number> = { debug: 20, info: 30, warn: 40, error: 50 };
const levelName = (n: number): LogLevel => (n >= 50 ? 'error' : n >= 40 ? 'warn' : n >= 30 ? 'info' : 'debug');
const KEEP = 5;

export const logDir = () => path.join(getConfig().dataDir, 'logs');

export function logFiles(dir: string): string[] {
  const names = ['dublyarr.log', ...Array.from({ length: KEEP - 1 }, (_, i) => `dublyarr.log.${i + 1}`)];
  return names.map((n) => path.join(dir, n)).filter(existsSync).reverse();
}

export function readLog(dir: string, f: { lines?: number; level?: LogLevel; area?: string; q?: string; since?: number } = {}): LogLine[] {
  const limit = Math.min(Math.max(1, f.lines ?? 500), 2000);
  const min = RANK[f.level ?? 'debug'];
  const q = f.q?.toLowerCase();
  const out: LogLine[] = [];
  for (const file of logFiles(dir).reverse()) {
    const rows = readFileSync(file, 'utf8').split('\n');
    for (let i = rows.length - 1; i >= 0 && out.length < limit; i--) {
      let j: Record<string, unknown>;
      try {
        j = JSON.parse(rows[i]);
      } catch {
        continue; // пустая или оборванная строка
      }
      const { time, level, area, name, msg, pid: _p, hostname: _h, ...data } = j as Record<string, unknown> & { time: number; level: number };
      if (RANK[levelName(level)] < min) continue;
      if (f.area && area !== f.area) continue;
      if (f.since && time < f.since) continue;
      if (q && !rows[i].toLowerCase().includes(q)) continue;
```

```ts
import type { TorznabItem } from './torznab';
import { TorznabError } from './torznab';
import { logger } from './log';

type Src = { url: string; apiKey: string; timeoutMs: number };
type Opts = { fetchImpl?: typeof fetch; sleep?: (ms: number) => Promise<void>; now?: () => number };
type Raw = { tracker?: string; url?: string; title?: string; size?: number; createTime?: string; sid?: number; pir?: number; magnet?: string | null; types?: string[] };

const slog = logger('search');
const sleepMs = (ms: number) => new Promise<void>((r) => setTimeout(r, ms));
const TYPES: Record<'series' | 'anime' | 'movie', string[]> = { series: ['tvshow', 'serial', 'multserial', 'docuserial'], anime: ['anime', 'tvshow', 'multserial'], movie: ['movie', 'multfilm', 'documovie'] };

// очередь на каждый адрес JacRed: по одному запросу, пауза ≥ 1 с
const queues = new Map<string, Promise<unknown>>();
function serial<T>(key: string, sleep: (ms: number) => Promise<void>, fn: () => Promise<T>): Promise<T> {
  const prev = queues.get(key) ?? Promise.resolve();
  const next = prev.catch(() => undefined).then(async () => {
    try {
      return await fn();
    } finally {
      await sleep(1000);
    }
  });
  queues.set(key, next);
  return next;
}

async function get(src: Src, path: string, o: Opts): Promise<unknown> {
  const fetchImpl = o.fetchImpl ?? fetch;
  const sleep = o.sleep ?? sleepMs;
  const url = `${src.url.trim().replace(/\/+$/, '')}${path}${src.apiKey ? `&apikey=${encodeURIComponent(src.apiKey)}` : ''}`;
  for (let attempt = 0; attempt < 2; attempt++) {
    let res: Response;
    try {
      res = await fetchImpl(url, { signal: AbortSignal.timeout(src.timeoutMs) });
    } catch (e) {
      if (e instanceof Error && (e.name === 'TimeoutError' || e.name === 'AbortError')) throw new TorznabError(`Нет ответа за ${String(src.timeoutMs / 1000).replace('.', ',')} с`, 'timeout');
      throw new TorznabError('JacRed не отвечает', 'network');
    }
    if (res.status === 429) {
      if (attempt === 1) break;
      const wait = Math.min(10, Number(res.headers.get('retry-after')) || 5) * 1000;
      slog.warn({ source: src.url, wait }, 'jacred 429');
      await sleep(wait);
      continue;
    }
    if (res.status === 401 || res.status === 403) throw new TorznabError('Неверный ключ JacRed', 'auth');
    if (!res.ok) throw new TorznabError(`HTTP ${res.status}`, 'http');
    try {
      return await res.json();
    } catch {
      throw new TorznabError('Ответ не похож на JacRed', 'bad');
    }
  }
  throw new TorznabError('JacRed не ответил: слишком много запросов', 'http');
}

const btih = (m: string) => /xt=urn:btih:([0-9a-f]{40})/i.exec(m)?.[1]?.toLowerCase() ?? null;

export async function jacredSearch(src: Src, q: string, kind: 'series' | 'anime' | 'movie', o: Opts = {}): Promise<TorznabItem[]> {
  const started = Date.now();
  const body = await serial(src.url, o.sleep ?? sleepMs, () => get(src, `/api/v1.0/torrents?search=${encodeURIComponent(q)}`, o));
  if (!Array.isArray(body)) throw new TorznabError('Ответ не похож на JacRed', 'bad');
  const want = new Set(TYPES[kind]);
  const items = (body as Raw[]).flatMap((r): TorznabItem[] => {
    const hash = r.magnet ? btih(r.magnet) : null;
    if (!hash || !r.title) return [];
    if (r.types?.length && !r.types.some((t) => want.has(t))) return [];
    return [{
      title: r.title, guid: r.url ?? hash, link: null, magnet: r.magnet!, details: r.url ?? null,
      publishedAt: r.createTime ? Date.parse(r.createTime) || null : null, size: r.size ?? 0,
      seeders: r.sid ?? null, peers: r.pir ?? null, infohash: hash, indexerId: r.tracker ?? null, indexerName: r.tracker ?? null,
      categories: [], attrs: {},
    }];
  });
  slog.debug({ source: src.url, q, found: items.length, ms: Date.now() - started }, 'jacred search');
  return items;
}

export async function jacredCheck(src: Src, o: Opts = {}) {
  const body = await serial(src.url, o.sleep ?? sleepMs, () => get(src, '/api/v1.0/torrents?search=test', o));
  if (!Array.isArray(body)) throw new TorznabError('Ответ не похож на JacRed', 'bad');
}
```

```ts
import { isIP } from 'node:net';

function v4Private(ip: string) {
  const [a, b] = ip.split('.').map(Number);
  return a === 127 || a === 10 || (a === 172 && b >= 16 && b <= 31) || (a === 192 && b === 168) || (a === 169 && b === 254);
}

export function isPrivateAddress(raw: string): boolean {
  const ip = raw.trim().replace(/^\[|\]$/g, '').replace(/%.*$/, '');
  const mapped = /^::ffff:(\d+\.\d+\.\d+\.\d+)$/i.exec(ip);
  if (mapped) return v4Private(mapped[1]);
  if (isIP(ip) === 4) return v4Private(ip);
  if (isIP(ip) === 6) {
    const l = ip.toLowerCase();
    return l === '::1' || /^f[cd][0-9a-f]{2}:/.test(l) || /^fe[89ab][0-9a-f]:/.test(l);
  }
  return false;
}

const forwardedFor = (v: string) => [...v.matchAll(/for="?\[?([^;,"\]]+)/gi)].map((m) => m[1].replace(/:\d+$/, ''));

/** Next.js сам ставит X-Forwarded-For = адрес сокета, если заголовка нет; прокси (Pangolin) передаёт внешний адрес. */
export function allLocal(h: { forwardedFor: string | null; realIp: string | null; forwarded: string | null }): boolean {
  const all = [...(h.forwardedFor?.split(',') ?? []), ...(h.realIp ? [h.realIp] : []), ...(h.forwarded ? forwardedFor(h.forwarded) : [])].map((s) => s.trim()).filter(Boolean);
  return all.length > 0 && all.every(isPrivateAddress);
}
```

```ts
import type { Db } from '../db/client';
import { apiTokens } from '../db/schema';
import { getSetting, setSetting } from '../settings';
import { hashToken, newToken } from '../auth/tokens';
import { allLocal } from './lan';

export const getApiEnabled = (db: Db) => getSetting<{ enabled: boolean }>(db, 'api')?.enabled ?? false;
export const setApiEnabled = (db: Db, on: boolean) => setSetting(db, 'api', { enabled: on });

export function createApiToken(db: Db, name: string, now = Date.now()) {
  const token = `dy_${newToken()}`;
  const row = db.insert(apiTokens).values({ name: name.trim() || 'Токен', hash: hashToken(token), prefix: token.slice(0, 8), createdAt: now }).returning({ id: apiTokens.id }).get();
  return { id: row.id, token };
}

export const listApiTokens = (db: Db) =>
  db.select({ id: apiTokens.id, name: apiTokens.name, prefix: apiTokens.prefix, createdAt: apiTokens.createdAt, lastUsedAt: apiTokens.lastUsedAt, lastIp: apiTokens.lastIp }).from(apiTokens).orderBy(apiTokens.id).all();

export const revokeApiToken = (db: Db, id: number) => db.delete(apiTokens).where(eq(apiTokens.id, id)).run();

type Headers = { authorization: string | null; forwardedFor: string | null; realIp: string | null; forwarded: string | null };

export function checkApiAccess(db: Db, h: Headers, now = Date.now()): { ok: true; tokenName: string } | { status: 401 | 403; error: string } {
  if (!getApiEnabled(db)) return { status: 403, error: 'API выключен' };
  if (!allLocal(h)) return { status: 403, error: 'Только из локальной сети' };
  const token = /^Bearer\s+(\S+)$/i.exec(h.authorization ?? '')?.[1];
  const row = token ? db.select().from(apiTokens).where(eq(apiTokens.hash, hashToken(token))).get() : undefined;
  if (!row) return { status: 401, error: 'Нужен токен API' };
  db.update(apiTokens).set({ lastUsedAt: now, lastIp: h.forwardedFor?.split(',')[0].trim() ?? null }).where(eq(apiTokens.id, row.id)).run();
  return { ok: true, tokenName: row.name };
}
```

```ts
import { handleApi } from '@/lib/api/router';
import { getQbit } from '@/lib/qbit';

async function handle(req: Request, { params }: { params: Promise<{ path: string[] }> }) {
  const db = getDb();
  const url = new URL(req.url);
  let body: unknown = undefined;
  if (req.method !== 'GET' && req.headers.get('content-type')?.includes('json')) body = await req.json().catch(() => undefined);
```
