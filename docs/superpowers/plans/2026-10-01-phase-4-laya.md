# Фаза 4 «Laya»: план реализации

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Laya решает четыре задачи (студия, тот ли сериал, нумерация аниме, финальная проверка) с порогом уверенности, учится на ответах пользователя через адаптеры с версиями и откатом; всё работает и без неё.

**Architecture:** Python — только ответы на вопросы (`laya/serve.py`, официальный пакет `laya`, модель в `/data/laya/base`); всё остальное — Node:
клиент `src/lib/laya/client.ts`, решения `src/lib/laya/decide.ts` (вопрос → признаки → адаптер → порог, кэш, бюджет), вопросы задач `src/lib/laya/tasks.ts`,
адаптер (логистическая регрессия) `src/lib/laya/adapter.ts`, примеры и версии `src/lib/laya/examples.ts`, `src/lib/laya/versions.ts`, ночная задача в воркере.

**Tech Stack:** как раньше + Python 3.11 venv в образе (`laya[onnx]`, PyTorch CPU).

**Spec:** `docs/superpowers/specs/2026-10-01-phase-4-laya-design.md`; `docs/spec.md` §3, §13; макеты `Settings.dc.html` («AI»), `AiTraining.dc.html`, `MobileAiTraining.dc.html`.

## Global Constraints

- Laya не генерирует текст: только `choice` / `noul` / `score`.
- Laya выключена, недоступна или задача выключена — поведение в точности как до фазы 4 (все прежние тесты зелёные без правок ожиданий).
- Порог по умолчанию 85 %; ниже порога — вопрос пользователю, ничего сомнительного не качается.
- Секреты не в логах; тексты интерфейса — на русском; образ — `linux/amd64`.
- Каждая задача — тест сначала, затем код, затем `pnpm test && pnpm typecheck && pnpm lint`.

## Review Focus

1. **Laya «зависла»** (ответ дольше 10 с, процесс перезапускается) — поиск не ждёт бесконечно, решения по правилам, три таймаута — пауза 10 мин. Тест в Task 2.
2. **Уверенное «нет» финальной проверки у всех трёх лучших** — ничего не качается, вопрос пользователю, отказ — пример. Тест в Task 7.
3. **Laya предложила студию, пользователь потом ответил «Нет»** — вариант написания убирается, раздачи переразбираются, пример сохранён. Тест в Task 5.
4. **Новая версия адаптера хуже на отложенных** — не применяется, текущая остаётся; версий не больше 3 + базовая. Тест в Task 9.
5. **Обновился пакет `laya` или ревизия модели** — адаптеры не применяются (базовая), ночью — переобучение на всех примерах. Тест в Task 9.
