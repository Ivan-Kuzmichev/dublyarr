# Фаза 2c «Расписание и уборка»: дизайн

Третья часть фазы 2 (2a надёжность → 2b озвучки и прогноз → **2c расписание и уборка** → 2d Telegram).
Источник правды — `docs/spec.md` §5 (расписание), §7 (уборка в qBittorrent); макеты — `Settings.dc.html` (разделы «Расписание», «Загрузка» → «Уборка в qBittorrent»).

## Решения владельца

- Расписание скорости действует **только на торренты Dublyarr** (категория `dublyarr`); чужие торренты и общие настройки qBittorrent не трогаются.
- Уборка с удалением файлов: **первое срабатывание — список с галочками**, после подтверждения — автоматически (CLAUDE.md).

## Что не входит

- Защита от переполнения диска (90/97 %) и экран «Хранилище» — фаза 3.
- Telegram — 2d.

## 1. Частота поиска

Настройка `schedule` (`app_settings`): `every`: `'15m' | '1h' | '2h' | '6h' | 'night'` (по умолчанию `'1h'`), `nightFrom`/`nightTo` (`'01:00'`/`'07:00'`), `eager` (по умолчанию `true`), `packChecks` (по умолчанию `true`).

Воркер раз в 5 минут — задача `subscriptions.tick`: для каждой подписки решает, пора ли (`searchDue`), и ищет только такие. `subscriptions.last_searched_at` пишется после поиска сериала (и при «Искать сейчас», который по-прежнему ищет все подписки).

`searchDue(sub, lastSearchedAt, now, settings, eager)`:
- `eager` и у сериала есть серия, которая ждёт озвучку (`wanted_state = waiting`), а прогноз (2b) — сегодня или уже прошёл → пора, если с прошлого поиска ≥ 30 мин (ночное окно не важно);
- `night` → только внутри ночного окна (окно может переходить через полночь), не чаще раза в час;
- иначе — если с прошлого поиска прошло ≥ интервала (15 мин / 1 ч / 2 ч / 6 ч). Ни разу не искали — пора.

Время — локальное время контейнера (`TZ`). `packs.check` — раз в 30 мин, если `packChecks`; иначе паки проверяются в конце поиска сериала.

## 2. Расписание скорости

Настройка `speed`: `limitMb` (по умолчанию 5), `grid`: 7×24 значений `'full' | 'limit' | 'pause'` (по умолчанию всё `'full'`), строки — пн…вс, столбцы — часы 0…23.

Раз в минуту (в `downloads.sync`) — `applySpeed(db, qbit, now)`:
- состояние ячейки «сейчас» (`speedAt(grid, now)`);
- `limit` — каждой качающейся загрузке Dublyarr лимит `limitMb / число качающихся` (МБ/с → байт/с), `full` — снять лимит (0); лимит переустанавливается только при изменении;
- `pause` — качающиеся (`downloading`, `stalled`) останавливаются, `downloads.paused_by_schedule = true`; при выходе из `pause` запускаются только отмеченные, отметка снимается. Остановленные вручную (`paused` без отметки) не будятся.
Клиент qBittorrent получает `setDownloadLimit(hashes, bytesPerSec)` (`POST /api/v2/torrents/setDownloadLimit`).
«Активность»: загрузка с отметкой — «Пауза по расписанию».
Подпись в разделе: «Сейчас: полная скорость / ограничено до 5 МБ/с / пауза · <следующее изменение> с 00:00» (`speedSummary`).

## 3. Уборка в qBittorrent (spec §7)

Настройка `cleanup`: `remove`: `'import' | 'seeded' | 'never'` (по умолчанию `'seeded'`), `seedDays` (3), `seedRatio` (2.0), `deleteFiles` (true), `replaced` (true), `orphans` (true).
Флаги подтверждения: `cleanup.files.confirmed` (удаление файлов вместе с торрентом), `cleanup.orphans.confirmed`.

Кандидаты (`cleanupPlan(db, qbit, paths, settings, now)`):
- **Импортированные** загрузки, чей торрент ещё в клиенте: `import` — сразу; `seeded` — когда с завершения прошло ≥ `seedDays` или рейтинг ≥ `seedRatio` (`ratio`, `completion_on` из `torrents/info`); `never` — нет.
- **Заменённые** (`replaced`, если `replaced` включено): их торрент уже убран из клиента (2a), остаются файлы.
- **Брошенные файлы** (если `orphans`): файлы в `{downloads}/dublyarr`, которые не принадлежат ни одному торренту категории `dublyarr` в клиенте и не моложе суток.

Для каждого кандидата-загрузки — какие файлы удалятся: файлы торрента (по `downloads.files`/`qbit.files`, путь через `toLocalPath`), **кроме** файлов, которые есть у любого живого торрента категории (путь совпадает). Удаляется только внутри `{downloads}/dublyarr` (проверка `path.relative`). Пустые папки после удаления убираются.

Выполнение (`runCleanup`, задача `cleanup.run` раз в час):
- торрент убирается из клиента (`deleteFiles=false`), запись — `state = removed`, `note` («Убран после раздачи: 3 дн / рейтинг 2,1» / «Убран после импорта»);
- файлы удаляются, только если `deleteFiles` и правило подтверждено; не подтверждено — торрент **не трогается** (ждёт подтверждения вместе с файлами);
- если `deleteFiles` выключено — торрент убирается сразу, без подтверждения (файлы не удаляются);
- брошенные файлы — только при подтверждённом правиле `orphans`.

Первое срабатывание: пока есть кандидаты с удалением файлов и правило не подтверждено — «Требует внимания»: «Уборка загрузок: N · X ГБ» → страница `/cleanup`: строки «сериал · раздача · причина · размер» и «брошенный файл · размер», галочки (по умолчанию все), «Освободится X ГБ», «Удалить отмеченные» (выполняет отмеченные, ставит флаги подтверждения затронутых правил), «Не сейчас».

## 4. Экран «Настройки → Расписание» и блок уборки

- `/settings/schedule` (макет «Расписание»): сегменты частоты, ночное окно (два поля времени), переключатели, подпись следующей проверки; сетка скорости 7×24 с выбором состояния кистью (кнопки «Полная / Ограничено / Пауза» и проведение по ячейкам; на телефоне — нажатие по ячейке), лимит — степпер.
- «Настройки → Загрузка и папки»: блок «Уборка в qBittorrent» по макету.

## Ошибки и крайние случаи

- qBittorrent недоступен — скорость и уборка пропускаются, поиск идёт по расписанию.
- Файл уже удалён руками — пропускается.
- Путь файла вне папки `dublyarr` — не удаляется, в лог.
- Торрент, нужный незавершённой загрузке (`adding/downloading/…`), не убирается.

## Тесты

Unit: `searchDue` (все частоты, окно через полночь, eager), `speedAt`/`speedSummary`, `applySpeed` (лимит делится, пауза и возврат только своих), `cleanupPlan` (каждое правило, общие файлы, пути), `runCleanup` (до/после подтверждения, `deleteFiles` выключено), брошенные файлы.
E2E: «Загрузка и папки» → «убирать сразу после импорта» → «Требует внимания» → `/cleanup` → «Удалить отмеченные» → торрент убран из заглушки, файлов в `qbit/dublyarr` нет, файлы в медиатеке на месте.
