# Фаза 2a «Надёжность загрузок»: дизайн

Первая часть фазы 2 (2a надёжность → 2b озвучки и прогноз → 2c расписание и уборка → 2d Telegram).
Источник правды по поведению — `docs/spec.md` §4 (п. 1 «Текущая раздача»), §5 (проверка паков раз в 30 мин), §7 (зависшие раздачи); здесь — как делаем.

## Цель

Новые серии из обновлённого топика докачиваются в ту же раздачу, а не отдельным торрентом; застрявшая раздача сама меняется на следующую;
закрыты недочёты, найденные итоговым ревью 1d.

## Что входит

1. Обновление пака по смене хэша топика — периодически и при обычном поиске.
2. Замена застрявшей раздачи.
3. Недочёты ревью 1d (список ниже).
4. Тексты в «Активности»: «Обновлена: +серия 6», «Заменена: нет сидов», «Пак · следим за обновлениями».

## Что не входит

- Удаление файлов из папки загрузок и уборка торрентов (2c). В 2a из клиента убирается только торрент (`deleteFiles=false`).
- Замена на озвучку выше по приоритету и на лучшее качество (2b).
- Настройка частоты проверок (2c): в 2a — постоянные 30 мин.

## Решения

### Топик

Раздача — это топик трекера; его адрес — `releases.details_url` (Torznab `comments`/`guid`). Две раздачи с одинаковым `details_url` у одного сериала — версии одного топика.
Нет `details_url` — раздача не отслеживается.

### Смена версии топика (`switchTorrent`)

Вход: прежняя загрузка `old` (не `replaced`/`removed`/`error`), новый `.torrent` того же топика, нужные серии `want`.

1. Хэш тот же — ничего не делаем (обычный путь `startRelease`).
2. Файлы нужных серий ищутся в новом торренте (`filesForEpisodes`). К `want` добавляются ещё не импортированные серии `old` (если `old` качается).
   Ни одной найденной — ничего не меняем, возвращаем «нет новых серий».
3. Новый торрент добавляется **в ту же папку** (`{qbitDownloads}/dublyarr`, как у всех раздач Dublyarr) на паузе; приоритет 1 — только файлам найденных серий, 0 — остальным;
   qBittorrent сам перепроверяет уже лежащие файлы.
4. Новая запись `downloads` (`kind: pack`, тот же `release_id`, `episodes` — найденные серии). Старый торрент убирается из клиента без файлов,
   старая запись: `state = replaced`, `replaced_by_id` = новая, `note` = «Обновлена: +серия 6» (или «+серии 6–7»).
5. Запуск нового торрента.

`startRelease` перед добавлением проверяет: есть ли у сериала живая загрузка с раздачей того же топика и другим хэшем → `switchTorrent` вместо нового торрента рядом.

### Проверка паков (`packs.check`, раз в 30 мин)

Отслеживаются загрузки, у которых: `kind = pack`; состояние не `replaced/removed/error`; у раздачи есть `details_url` и ссылка на `.torrent`; сериал в подписке;
в сезоне загрузки есть серии без файла в медиатеке, которые нужны по подписке или ещё не вышли (дата в будущем или не объявлена).
Для каждой — скачать `.torrent` по сохранённой ссылке (Jackett отдаёт текущую версию топика), сравнить хэш; другой → нужные серии этого сезона
(вышедшие, по подписке, без файла и не в другой живой загрузке) → `switchTorrent`. Ошибка одной проверки не мешает остальным; без qBittorrent проверка не идёт.

### Застрявшая раздача

Загрузка `stalled` (с 1d: больше суток без сидов, не докачана) не считается «уже качается» для своих серий при поиске по подписке, а её раздача для этих серий — отвергнутой.
Если замена нашлась и стартовала — серии убираются из `episodes` застрявшей; не осталось ни одной — торрент убирается из клиента,
`state = replaced`, `note` = «Заменена: нет сидов», `replaced_by_id`. Замены нет — застрявшая остаётся, серия «качается».

### Недочёты ревью 1d

- Год в имени файла («Show - 2023 - 03») не принимается за номер серии: числа 1900–2099 из четырёх цифр не считаются номером в правиле « - N».
- Гонка ручного «Скачать» и воркера: если `add` вернул отказ, а торрент с этим хэшем уже в клиенте, или вставка упёрлась в уникальный хэш — дополняем существующую загрузку (`enableFiles`).
- «Сезон целиком после финала»: серии сезона — только нужные по подписке и без файла.
- Сезон считается законченным и при сериях без даты в TMDB, если среди раздач есть пак, заявляющий весь сезон («Серии: 1–N из N»): тогда N — число серий.
- `wanted_state`: при поиске по подписке удаляются записи серий, которые больше не нужны; ручное «Скачать» снимает их с запущенных серий.
- Импорт не затирает чужой файл: если по пути уже лежит файл, который не записан в `episode_files` как импорт этой же серии, — ошибка «Файл уже есть в медиатеке: …».
- «Пауза/Продолжить/Убрать из клиента»: только для подходящих состояний и при подключённом qBittorrent; иначе — ничего и сообщение.
- Сбой включения файлов у одной серии не прерывает поиск по подписке; сбой `files` у одной загрузки не прерывает синхронизацию остальных.
- Клиент qBittorrent переиспользуется между вызовами (одна сессия на настройки), повторный вход — только при 403.

### Данные

`downloads`: состояние `replaced`; колонки `replaced_by_id` (ссылка на `downloads.id`, set null), `note` (текст для «Активности»). Миграция 0006.

### Экраны

«Активность»: заменённые загрузки видны сутки, как импортированные, с текстом `note`; у качающегося пака с топиком — подпись «Пак · следим за обновлениями».

## Ошибки и крайние случаи

- `.torrent` по ссылке не скачался — проверка этого пака пропускается до следующего раза.
- Новая версия топика — другой сезон или вовсе не тот сериал (топик переделали): нужных файлов нет → «нет новых серий», ничего не меняется.
- Старый торрент уже убрали руками — `switchTorrent` всё равно добавляет новый; ошибка удаления старого не мешает.

## Тесты

- Unit: `switchTorrent` (та же папка, приоритеты, старый убран, `replaced` + `note`, перенос недокачанных серий, «нет новых серий»); `startRelease` выбирает `switchTorrent` для того же топика;
  отбор отслеживаемых паков; `checkPacks` (сменился/не сменился хэш, ошибка одной проверки); замена застрявшей; каждый недочёт из списка.
- E2E: заглушки TMDB и Jackett получают переключатели «серия 3 вышла» и «топик обновлён» → «Искать сейчас» → в «Активности» «Обновлена: +серия 3» → серия 3 в медиатеке.
