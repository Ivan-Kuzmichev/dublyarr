# Фаза 3b «Хранение»: дизайн

Вторая часть фазы 3 (3a пересборка → **3b хранение** → 3c фильмы). Источник правды — `docs/spec.md` §8; CLAUDE.md («удаление только по правилам, первое срабатывание — с подтверждением»);
макеты — `Storage.dc.html`, `MobileStorage.dc.html`, `Settings.dc.html` (раздел «Хранение»).

## Решения владельца

- Правило «Сезоны: последний + выходящий» — **по умолчанию выключено**, включается в настройках.
- «Удалить сериал → файлы» — удаляются и его торренты с файлами в папке загрузок `dublyarr` (кроме файлов, нужных другим торрентам).

## Что не входит

- Фильмы в «Хранилище» и правилах — 3c.
- Файлы медиатеки, не записанные как серии Dublyarr, — никогда не удаляются (только учитываются как «Не Dublyarr»).

## 1. Правила

Настройка `retention`:
- `seasons`: `{ on: false, keep: 1, ended: 'keep' | 'clean' }`;
- `oldCopy`: `'now' | '3days' | 'cleanup'` (по умолчанию `'now'`, как в 2b);
- `age`: `{ days: 30 }` (включается у сериала флагом);
- `overflow`: `{ on: true, warn: 90, pause: 97 }`;
- `schedule`: `'daily' | 'weekly' | 'manual'` (по умолчанию `'weekly'`), время — 04:00, неделя — воскресенье.

Подписка: `keep_all` («хранить все сезоны» — исключение для правила сезонов), `auto_delete` («удалять через N дней» для этого сериала).

**Сезоны** (`seasons.on`): сериал в подписке, без `keep_all`; «выходящий» сезон — последний сезон по TMDB, у которого есть серии с датой в будущем или без даты; «вышедшие» — остальные с номером > 0.
Если выходящего нет и сериал не завершён — выходящим считается последний. Сезон «скачан целиком» — все его вышедшие (`air_date ≤ сегодня`) серии есть в `episode_files`, и у каждой `dub_position = 0` (или не известна).
Удаляются сезоны старше: последних `keep` вышедших сезонов + выходящего, — но только когда выходящий (или, если его нет, последний вышедший) скачан целиком.
Завершённый сериал (`status` ended/canceled): `ended = 'keep'` — не трогается; `'clean'` — остаются последние `keep` сезонов.

**Старая копия**: `now` — как в 2b (удаляется сразу после подтверждения правила); `3days` — удаляется на уборке, если ей ≥ 3 дней; `cleanup` — на ближайшей уборке. До первого подтверждения — скрытая папка (2b).

**N дней** (`auto_delete` у сериала): удаляются серии, импортированные ≥ `age.days` дней назад.

## 2. Уборка

`retentionPlan(db, media, settings, now)` → элементы `{ key, rule, titleId, label, why, files: { episodeFileId?, oldCopyId?, path }[], size }`
(«Гриффины · S01–S22», «старше последнего вышедшего сезона»; «Рик и Морти · 1080p-копии», «заменены версиями в 2160p»).
`runRetention(db, media, settings, now, opts?: { confirmKeys })` — как уборка загрузок 2c: правило не подтверждено — ничего не удаляет, элементы — в сводку (`app_settings['retention.pending']`) и «Требует внимания»;
с `confirmKeys` — выполнить отмеченные, включить правила, неотмеченные — «не удалять» (`retention.declined`).
Флаги подтверждения: `retention.seasons.confirmed`, `retention.oldCopy.confirmed` (тот же, что в 2b), `retention.age.confirmed`.
Удаление: файл медиатеки (путь внутри медиатеки, записан в `episode_files` или `old_copies`), строка `episode_files`/`old_copies`, опустевшие папки сезона и сериала; запись в `deletions` (`title_id`, `label`, `why`, `size`, `at`).
Расписание: задача `retention.run` — по `retentionDue(schedule, lastRun, now)` (04:00 каждый день / по воскресеньям; `manual` — только «Запустить сейчас»). Сводка «ждёт подтверждения» — в Telegram (2d).

## 3. Защита от переполнения

`diskUsage(media)` — `fs.statfs` тома медиатеки → `{ total, free, used, pct }`. Раз в минуту (в `downloads.sync`): `pct ≥ warn` — «Требует внимания» и Telegram (раз в сутки) «Диск заполнен на 91 %»;
`pct ≥ pause` — `app_settings['storage.paused'] = true`, `applySpeed` ставит загрузки Dublyarr на паузу (как пауза по расписанию, отметка `paused_by_schedule`); ниже порога — снимается.
«Активность»: «Пауза: мало места».

## 4. Удаление сериала

`deleteSeries(db, deps, titleId, mode)`, `mode`: `'all'` | `'files'` | `'sub'`:
- `files`/`all`: все файлы медиатеки сериала (`episode_files`, `old_copies`), его торренты (`downloads` в клиенте — убрать без файлов клиентом, файлы удалить Dublyarr внутри `{downloads}/dublyarr`, кроме файлов других живых торрентов), записи `downloads` → `removed`, `wanted_state` очищается, запись в `deletions`;
- `sub`/`all`: отписка.
Подтверждение — диалог (действие пользователя).

## 5. Экраны

- **«Хранилище»** `/storage` (`Storage.dc.html`, `MobileStorage.dc.html`): «NAS · <путь медиатеки>», занято / из / свободно, полоса (сериалы, аниме, Не Dublyarr, свободно);
  «По сериалам» (на диске S01–S09, качество, размер, правило: «исключение: все» / «S08 + выходящий» / «завершён» / «выходящий» / «через 30 дн», полоса «останется / уйдёт», корзина → диалог), сортировка по размеру / по дате;
  справа — «Первая уборка по правилу …» (если ждёт подтверждения: галочки, «Освободится», «Удалить отмеченное» / «Позже»), «Прогноз» (ГБ в неделю по последнему месяцу, недель до заполнения — сейчас и после уборки), «Недавно удалено».
- **«Настройки → Хранение»** (по макету): «Уборка» (частота, следующая, «освободит X», «Запустить сейчас»), карточки правил, «Открыть хранилище».
- **Карточка сериала**: переключатели «Хранить все сезоны» и «Удалять через N дней после скачивания», кнопка «Удалить…» → тот же диалог.

## Тесты

Unit: план сезонов (выходящий/вышедший, `keep`, «скачан целиком», завершённые, исключение), старая копия (три режима), N дней, подтверждение и «не удалять», история, расписание уборки, диск и пауза, удаление сериала (три режима, общие файлы, пути), данные «Хранилища».
E2E: «Хранилище» → удалить сериал «только файлы» → файлов в медиатеке нет, подписка на месте.
