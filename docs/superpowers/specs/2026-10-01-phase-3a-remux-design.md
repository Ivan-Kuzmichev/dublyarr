# Фаза 3a «Пересборка файлов»: дизайн

Первая часть фазы 3 (**3a пересборка** → 3b хранение → 3c фильмы). Источник правды — `docs/spec.md` §6; макет — `Settings.dc.html`, раздел «Обработка файлов».

## Цель

В медиатеке лежит серия с нужными дорожками и флагами: VidHub сразу включает озвучку из подписки и форсированные субтитры. Не та серия (фильм вместо серии) не попадает в медиатеку.

## Что не входит

- Удаление исходника после раздачи — уже делает уборка 2c.
- Перекодирование — никогда (только `mkvmerge` без перекодирования).

## 1. Настройки

`app_settings['processing']`:
- `audio`: `'dub+original'` (по умолчанию) | `'dub'` | `'all'`;
- `keepBackups` (false) — оставлять озвучки других позиций профиля;
- `external` (true) — вшивать внешние `.mka`/`.srt` из раздачи;
- `defaultSubs`: `'none'` | `'forced'` (по умолчанию) | `'full'`;
- `keepSubs`: языки субтитров (по умолчанию `['rus', 'eng']`).

## 2. Разбор и выбор дорожек

`ffprobe -v error -print_format json -show_streams -show_format <файл>` → дорожки (`index`, `codec_type`, `codec_name`, `tags.language`, `tags.title`, `disposition.default/forced`, `width/height`, цветовые признаки HDR), длительность.
HDR — `color_transfer` `smpte2084`/`arib-std-b67` или признак Dolby Vision в `side_data_list`.

Опознание аудио (чистая функция `classifyAudio`):
- студия — название дорожки (или `handler_name`) содержит каноническое имя или вариант написания студии из словаря (нормализация `normalizeStudio`, целыми словами);
- оригинал — язык дорожки = язык оригинала сериала (TMDB `original_language` → ISO 639-2) или в названии «original»/«оригинал»/«orig»;
- иначе — «другая».

Выбор (`planTracks`, чистая функция):
- видео — все видеодорожки (обычно одна);
- аудио: нужная озвучка — дорожки студии позиции профиля, по которой взята серия (`dubPosition`), для «Любой» — студия раздачи (`studioLabel`);
  `dub+original` — нужная + оригинал; `dub` — только нужная; `all` — все; `keepBackups` — плюс дорожки студий других позиций профиля;
  **нужная не опознана ни в одной дорожке — аудио не трогаем (все дорожки, флаги не меняем)**; порядок: нужная, затем оригинал, затем остальные выбранные;
- субтитры — с языком из `keepSubs` или без языка; форсированные — `disposition.forced` или «forced»/«форс»/«надписи» в названии; по умолчанию: `forced` → первая русская форсированная, `full` → первая русская полная, `none` — нет;
- флаги «по умолчанию»: нужная озвучка (или прежний, если не опознана) и выбранные субтитры; остальные — сняты;
- внешние дорожки: файлы `.mka`/`.ac3`/`.eac3`/`.dts`/`.srt`/`.ass` из той же раздачи, относящиеся к этой серии (`episodeFromFilename` по имени файла; один видеофайл — все внешние), язык и студия — по имени файла и папкам («Rus Sound/LostFilm/…»).
- **менять нечего** (все дорожки остаются, флаги уже такие, контейнер mkv, внешних нет) → пересборки нет, импорт жёсткой ссылкой как раньше.

## 3. Проверка «та ли серия»

Длительность файла против `episodes.runtime` (TMDB, минуты): вне `[0,5×; 2×]` → не та серия. Нет `runtime` — проверка длительности только «больше 100 мин для серии» как признак фильма.
Не та серия: файл не импортируется; загрузка (если все её серии такие) — `error` «Не та серия: 2 ч 10 мин вместо ~55 мин», раздача отвергается для этой серии (как ошибка «нет файла» в 2a), торрент убирается из клиента без файлов, поиск сериала — в очередь.
Реальные разрешение (по высоте/ширине кадра) и HDR записываются в `episode_files.resolution`/`hdr`.

## 4. Сборка

`mkvmerge -o <tmp в медиатеке> [--audio-tracks …] [--subtitle-tracks …] [--track-order …] [--default-track-flag id:0|1 …] [--language id:rus …] <источник> [внешние с --language/--track-name]`.
Временный файл — рядом с целевым (`.dy-*.tmp.mkv`), затем постановка на место по правилам импорта (чужой файл не затирается, старая копия — правило 2b). Расширение результата — `.mkv`.
Ошибка `mkvmerge` (код ≥ 2) → импорт этой серии не удался, текст ошибки в загрузке; код 1 (предупреждения) — успех.
Программы запускаются через интерфейс `Runner` (`execFile` с таймаутом; в тестах — подмена). Нет `mkvmerge`/`ffprobe` — обработка выключена, импорт как раньше; статус «Обработка недоступна: нет mkvmerge».

## 5. Данные

`episode_files`: `processed` (bool), `hdr` (bool), `duration` (сек), `tracks` (JSON: что было и что стало — для примера в настройках и карточки).
`episodes.runtime` уже есть.
«Активность»: загрузка во время пересборки — «Пересборка…» (состояние `completed` + отметка `processing`).

## 6. Экраны

- «Настройки → Обработка файлов» — по макету: варианты аудио, два переключателя, «По умолчанию в плеере», пример «В раздаче → В библиотеке» по последнему пересобранному файлу (с размерами), статус доступности программ.
- Карточка сериала: в подстроке файла — «HDR» и «пересобран».

## Ошибки и крайние случаи

- Повреждённый файл (ffprobe не читает) — импорт не удался, «Файл не читается».
- Нет места при сборке — ошибка, временный файл удаляется, источник не тронут.
- Несколько видеодорожек — все остаются.
- Внешняя дорожка не опознана по языку — добавляется без языка, не по умолчанию.

## Тесты

Unit: `classifyAudio`, `planTracks` (озвучка + оригинал, только озвучка, всё, запасные, нужная не опознана — не трогаем, субтитры по умолчанию, менять нечего), аргументы `mkvmerge`, проверка длительности, поиск внешних файлов, импорт с подменённым `Runner` (пересборка, жёсткая ссылка когда менять нечего, «не та серия»).
В образе Docker: скрипт `scripts/remux-smoke.sh` — `ffmpeg` делает mkv с видео, тремя аудио (en, «HDrezka», «LostFilm») и двумя субтитрами, Dublyarr-функция пересобирает, `ffprobe` результата сверяется.
