# Фаза 3c «Фильмы»: дизайн

Последняя часть фазы 3 (3a пересборка → 3b хранение → **3c фильмы**). Источник правды — `docs/spec.md` §10; макет — `Settings.dc.html`, раздел «Фильмы».
Карточки фильма в макетах нет — рисуется в стиле карточки сериала (`Series.dc.html`, `MobileSeries.dc.html`).

## Решения владельца

- **Вариант A:** фильм — `titles` с `kind = 'movie'`, подписка — та же `subscriptions`, файл — `episode_files` с условным номером S00E00 (`MOVIE_EP`).
  Загрузки, импорт, пересборка (3a), старые копии, хранение и удаление (3b), Telegram работают без второго пути.
- **У каждого фильма своя копия всех правил** (как профиль сериала); профиль по умолчанию — «Настройки → Фильмы».
- **Фильмы — вкладка в «Библиотеке»** (Сериалы / Аниме / Фильмы), плюс поиск и тренды, «Сегодня», «Календарь».

## Что не входит

- Коллекции и франшизы, автоподписка на продолжения (spec §11 — только сериалы).
- Одноголосые и авторские переводы — не берутся.

## 1. Каталог

TMDB: `movie/{id}?append_to_response=release_dates,alternative_titles` (`ru-RU`, пустое описание — `en-US`), поиск `search/multi` (сериалы и фильмы), тренды `trending/all/week`.
`titles` для фильма: `kind = 'movie'`, `year` — по дате премьеры, `status` — `released` / `planned` (`in_production` → `planned`), `runtime` (мин),
`releaseDates` (JSON: `{ theatrical, digital, physical }` — самая ранняя дата типов 3, 4, 5 в `release_dates`, в приоритете RU, иначе US, иначе любая).
Сезонов и серий у фильма нет. Освежение — как у сериалов (карточка старше 12 ч; `tmdb.refresh-all`: не вышедшие цифрово — ежедневно, остальные — раз в 30 дней).
`kind` фильма вручную не меняется.

## 2. Профиль фильма

```ts
type MovieDub = { kind: 'dub' | 'mvo' | 'original'; on: boolean }; // порядок = приоритет
type MovieProfile = {
  type: 'movie';
  dubs: MovieDub[];          // по умолчанию dub, mvo, original — все вкл.
  waitDubDays: number;       // 14 — ждать дубляж после цифрового релиза
  quality: Quality;          // как у сериала (target, allowLower, preferHdr, maxSizeGb: 30)
  noCam: boolean;            // true — не качать экранки
  digitalOnly: boolean;      // true — ждать цифровой релиз
  remux: boolean;            // false — улучшить до BDRemux
  replaceWithDub: boolean;   // true — заменить на дубляж
};
```
`subscriptions.profile` — `Profile | MovieProfile` (`type: 'movie'` различает); сериальный код получает только `Profile` (`isMovieProfile`).
По умолчанию — `app_settings['profile.movie']`, иначе встроенный. Проверка формы — на сервере (`validateMovieProfile`).

## 3. Цифровой релиз

Цифровой релиз состоялся, если есть хоть одно из:
- в TMDB дата цифрового (тип 4) или физического (тип 5) релиза ≤ сегодня;
- на трекерах видели раздачу этого фильма с источником WEB-DL / WEBRip / BDRip / Remux (`movie_digital_seen` — дата первого наблюдения в `titles.digitalSeenAt`).

Дата цифрового релиза (для ожидания) — самая ранняя из этих дат.

## 4. Поиск и вердикт

Поиск — `searchTitle` для фильма: запросы «ru-название год», «оригинальное название год», категории Torznab 2000/2040/2045/2050/2060.
Разбор — `parseRelease` (как есть). «Тот ли фильм» (`matchMovie`): название (0,7) + год ±1 (0,2) + размер 0,7–100 ГБ (0,1); заголовок с сезоном/серией — не фильм.

`evaluateMovie(releases, ctx)` → вердикты `{ releaseId, ok, reason?, dubPos, resolution, score }`. Отказ с причиной (видна в ручном поиске):
- экранка (`screener` или `source = 'cam'`) при `noCam` — «Экранка»;
- источник не цифровой при `digitalOnly` (`hdtv` и неизвестный при наличии цифровых — «Не цифровой релиз»; DVD — цифровой);
- больше лимита — «Больше 30 ГБ»; качество ниже целевого без «брать ниже», выше целевого — «Выше 1080p»;
- перевод: позиция = первая включённая позиция профиля, которую даёт раздача (`dub` → «Дубляж», `mvo`/`dvo` → «Многоголосый», `original`+`subs` или только `original` → «Оригинал + субтитры»); нет ни одной — «Нет нужного перевода»;
- правила пользователя (`release-rules`) — как у сериалов.
Лучшая: позиция перевода выше → качество ближе к целевому (HDR при `preferHdr`) → Remux при `remux` → сиды.

**Ожидание:** позиция `dub` открыта сразу; `mvo` и `original` — когда цифровой релиз состоялся и прошло `waitDubDays` от его даты.
Выбор — лучшая из открытых позиций. Статус (`wanted_state` для `MOVIE_EP`): «Ждём цифровой релиз» (не состоялся, `digitalOnly`) /
«Ждём дубляж до 12 окт» (есть раздача ниже дубляжа, окно не открыто) / «Нет раздач» / «Нужен ответ» (сомнительное совпадение).

## 5. Загрузка и импорт

`startRelease` для фильма: раздача добавляется на паузе, из списка файлов включается основной видеофайл (самый большой `.mkv/.mp4/.avi/.m2ts`, кроме `sample`/`trailer`/`extras`), внешние `.mka/.srt` — включаются (3a вшивает).
`downloads.episodes = [MOVIE_EP]`. Импорт — папка фильмов `paths.movies` (настройка в «Загрузка и папки», обязательна для фильмов), шаблон
`{Название} ({Год})/{Название} ({Год}) [{Перевод} {Качество}]` (`paths.movieTemplate`). Пересборка 3a: нужная озвучка — по типу перевода (дорожка с «дубл»/«dub» / «MVO»/«многоголос» в названии, иначе русская), длительность сверяется с `runtime` фильма.
`episode_files.dubPosition` — индекс позиции профиля (как у сериалов), `episode_files.path` — относительно папки фильмов.

## 6. Замена

- **На дубляж** (`replaceWithDub`): файл не в позиции `dub` — поиск продолжается 180 дней от импорта; найден дубляж в пределах правил — качается, старый файл — старая копия (2b/3b).
- **До BDRemux** (`remux`): файл не Remux — найден Remux той же или лучшей позиции перевода в лимите — качается так же.
- Подпись в «Активности» и Telegram — «Улучшение: многоголосый → дубляж» / «Улучшение: WEB-DL → BDRemux».

## 7. Хранение и диск

`deleteMediaFile` и правила хранения получают корень по виду фильма (`paths.movies` для `kind = 'movie'`). Правило сезонов к фильмам не применяется; «через N дней» и старые копии — применяются.
«Хранилище»: сегмент «Фильмы», строка фильма (размер, перевод, качество, правило). Защита от переполнения — по обоим томам (самый заполненный).
Удаление фильма — тот же диалог (варианты «файлы и подписка» / «только файлы» / «только подписка»).

## 8. Экраны

- **Карточка фильма** `/movie/[tmdbId]`: шапка как у сериала (постер, оригинальное название · год · длительность · жанры, название), кнопки «Подписка» / «Ручной поиск» / «Обновить из TMDB»;
  лента «Кинотеатры → Цифровой релиз → Дубляж → В медиатеке» (даты; прогноз «ждём дубляж до …» — пунктирная янтарная рамка; скачано — светлая заливка),
  блок файла (перевод, качество, HDR, размер, «пересобран»), панель подписки, «Хранение» (через N дней) и «Удалить…». Телефон — одна колонка.
- **Окно подписки** — вариант для фильма (`MovieProfileEditor`): перевод (порядок, вкл/выкл), «ждать дубляж N дн», качество и лимит, четыре флага.
- **«Настройки → Фильмы»** — по макету (профиль по умолчанию + «Как это выглядит» по последнему фильму в подписках).
- **«Библиотека»** — вкладка «Фильмы»: постеры со статусом («Дубляж · 2160p · 24 ГБ» / «Ждём цифровой релиз» / «Ждём дубляж до …» / «Нет раздач»).
- **«Поиск и тренды»** — фильмы в результатах и популярном (метка «Фильм»).
- **«Сегодня»** — «Ждём озвучку» и «Требует внимания» включают фильмы; **«Календарь»** — даты цифровых релизов фильмов в подписке.
- **Ручной поиск** `/search/[tmdbId]` — для фильма без сезона/серии, с причинами отказа.
- **«Загрузка и папки»** — поле «Папка фильмов» и шаблон.

## Ошибки и крайние случаи

- Папка фильмов не задана — подписка возможна, загрузка не стартует, статус «Не задана папка фильмов» в «Требует внимания».
- В раздаче несколько больших видеофайлов (две версии) — берётся самый большой; DVD/BD-структура (`VIDEO_TS`, `BDMV`) — отказ «Диск, а не файл».
- В TMDB нет дат релиза — работает только по раздачам.
- Сериал и фильм с одним tmdb id — разные сущности TMDB: `titles.tmdbId` уникален в паре с видом (`tmdb_type`: `tv`/`movie`).

## Тесты

Unit: маппинг TMDB фильма и дат релиза, профиль (проверка, по умолчанию), `matchMovie`, `evaluateMovie` (экранка, цифровой, лимит, перевод, ожидание и статусы),
выбор файла в раздаче, импорт в папку фильмов, замена на дубляж и до Remux, хранение (корень, сегмент), данные карточки и библиотеки.
E2E (`11-movies`): найти фильм в поиске → подписка → на трекере многоголосый (окно дубляжа не открыто — «Ждём дубляж до …») → появился дубляж → загрузка → файл в папке фильмов, на карточке «В медиатеке».
