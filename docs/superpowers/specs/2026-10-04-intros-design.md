# Заставки и титры: дизайн

VidHub показывает кнопки «Пропустить заставку / титры», если в `.mkv` есть главы заставки и титров (документация Oka Apps).
Dublyarr сам находит опенинг и эндинг по общему звуку серий сезона и вписывает главы. Медиасервера нет — разметка только в файле.

## Решения владельца

- Размечать заставку **и** титры, у новых серий и у всего, что уже лежит в медиатеке.
- Файлы с главами от релиз-группы **не трогать**.
- Жёсткую ссылку на раздачу — **разрывать**: копия файла в медиатеке, главы — в копию (место на диске × 2, пока идёт раздача).
- В интерфейсе — только отметка «размечено» у серии, без времени.

## Что не входит

- Фильмы.
- Не-mkv (после 2.3.1 всё, что читает mkvmerge, и так становится mkv; `.wmv` — пропускается).
- Распознавание по картинке, по субтитрам, ручная правка времени.
- Laya (здесь нечего решать вариантами — только сравнение звука).

## 1. Поиск

Отпечатки звука — Chromaprint через ffmpeg (`-f chromaprint -fp_format raw`, моно), шаг кадра ≈ 0,1238 с (4096 / 3 / 11025).
Окна: **начало** — первые 10 мин серии, **конец** — последние 4 мин. Отпечатки кэшируются файлами `${DATA_DIR}/cache/fp/<episodeFileId>-<size>-<head|tail>.bin`.

Сравнение пары серий (`commonSegment`): кандидаты сдвига — по совпадающим значениям отпечатков (обратный индекс, как Intro Skipper в Jellyfin),
для каждого сдвига — самый длинный отрезок, где расстояние Хэмминга кадров ≤ 8 бит (допускается до 3 «плохих» кадров подряд внутри).
Годится отрезок длиной 15–120 с.

Для серии берутся до 4 ближайших по номеру серий того же сезона с файлами (по 2 с каждой стороны, если есть).
Найденные с каждым соседом отрезки (в координатах этой серии) группируются: отрезки «согласны», если начала и концы отличаются ≤ 3 с.
**Уверенно** — группа из ≥ 2 согласных отрезков; или в сезоне всего 2 серии и отрезок ≥ 20 с. Итог — медиана начал и концов группы.
Заставка и титры ищутся независимо: может найтись одно из двух.

## 2. Запись

Главы (по порядку, пустые и короче 1 с — пропускаются):
`Начало` (0 → заставка) · `{intro}` (заставка) · `Серия` (после заставки → титры) · `{credits}` (титры) · `После титров` (→ конец).
`{intro}`/`{credits}` — из настройки (по умолчанию `Intro` / `Credits`). Запись — `mkvpropedit <файл> --chapters <файл глав>` (простой формат OGM).

Перед записью: файл тот же (путь и размер как в `episode_files`), это `.mkv`, своих глав нет (`ffprobe -show_chapters`).

- Файл — своя копия (`processed` или ссылок на inode 1): правка на месте.
- Жёсткая ссылка (ссылок > 1): только если диск медиатеки заполнен < порога «предупредить» из правил хранения (90 %).
  Копия во `{media}/.dublyarr-tmp`, главы — в копию, `rename` поверх файла медиатеки (раздача остаётся на исходнике); `method = 'copy'`.
  Диск полон — серия ждёт (`waiting`), проверяется снова при следующем проходе.

## 3. Когда

Задача воркера `intros.tick` раз в 10 мин (если включено): берёт **один** сезон, где есть файлы, требующие работы, и обрабатывает его целиком.
Требуют работы: `intro_state` пусто (новый или заменённый файл) или `waiting`. Так проходится и вся медиатека после обновления, и новые серии.
Импорт серии (новой или замены) сбрасывает её отметку, а у серий того же сезона с `none` — тоже сбрасывает (появился новый сосед).
Сбой ffmpeg/mkvpropedit по файлу — `error` с текстом, без повторов до замены файла; остальной сезон продолжает.

## 4. Данные

`episode_files` += `intro_state` (`marked` | `none` | `skipped` | `waiting` | `error`, null — не проверено), `intro_note` (причина: «свои главы», «не mkv», «мало серий», текст ошибки),
`intro_start`, `intro_end`, `credits_start`, `credits_end` (мс; для API и журнала). `intro_checked_at` — когда проверяли (`waiting` — не чаще раза в час, чтобы не загораживать другие сезоны). Импорт пишет все эти поля как null (upsert заменяет и их).
Настройка `app_settings['intros']` = `{ on: true, introName: 'Intro', creditsName: 'Credits' }`.

## 5. Интерфейс

- Карточка сериала: в строке скачанной серии — «· размечено» (как «· пересобран»), только для `marked`.
- «Настройки → Файлы»: карточка «Заставки и титры» — переключатель «Размечать главы для пропуска в плеере» и два поля «Название главы заставки / титров».
  Выключение останавливает разметку; вписанные главы остаются.

## Ошибки и крайние случаи

- Нет ffmpeg с chromaprint или mkvpropedit — задача ничего не делает (как пересборка без mkvmerge).
- Серия короче 5 мин — окна обрезаются по длительности; начало и конец не пересекаются (конец — не раньше середины серии).
- Файл заменили (улучшение, удаление) во время прохода — проверка пути/размера перед записью, запись пропускается.
- Сезон из 1 серии — `none` («мало серий») до появления второй.
- Временные копии в `.dublyarr-tmp` чистятся при старте воркера (как у пересборки).

## Тесты

Unit: `commonSegment` на синтетических отпечатках (общий кусок со сдвигом, шум ±бит, слишком короткий/длинный), согласование соседей (2 согласных → да, 1 → нет, сезон из 2 серий),
главы (полный набор, заставка с 0, без титров), решение записи (копия → на месте; ссылка + диск < 90 % → копия; ссылка + диск полон → `waiting`; свои главы → `skipped`),
выбор сезона задачей и сбросы при импорте, upsert обнуляет поля.
В образе: `scripts/intro-smoke.sh` — ffmpeg генерирует 3 «серии» с одинаковым 30-секундным куском в разных местах среди разного звука → задача находит его (±1 с) и вписывает главы.
