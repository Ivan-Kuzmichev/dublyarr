# Фаза 1c «Поиск и разбор»: дизайн

Третья часть фазы 1 (1a каталог → 1b подписки → **1c поиск и разбор** → 1d загрузки).
Источник правды по поведению — `docs/spec.md` §2–3; здесь — как делаем.

## Цель

По подписке найти раздачи во всех Torznab-источниках, разобрать заголовки, понять, тот ли это сериал и какие в раздаче озвучки,
и для каждой нужной серии сказать, какая раздача лучшая и почему остальные не подходят. В 1c это видно в «Ручном поиске»;
1d возьмёт ту же оценку для автоматики.

## Что входит

- Таблицы `trackers`, `releases`, `release_rules`; правка подписи/проверки ожиданий в профиле (1b).
- Клиент Torznab (поиск, список трекеров), опрос источников, дедупликация, основной/запасной источник трекера.
- Разбор заголовка `parseRelease`, распознавание озвучек по словарю, сквозная нумерация аниме.
- Оценка «тот ли сериал» `matchRelease`, правила «это он / не он».
- Оценка для подписки `evaluateReleases` с вердиктами и выбором лучшей.
- Экраны: «Ручной поиск» (по `Activity.dc.html`, правая часть), «Настройки → Источники» (по `Settings.dc.html`, раздел «Источники»).

## Что не входит

- Поиск по расписанию, загрузка, очередь «Активности», «Сегодня», «Календарь» — 1d.
- Laya (фаза 4): сомнительное совпадение и нераспознанная студия → вопрос пользователю; место под финальную проверку — пустая функция.
- Статистика задержек студий — фаза 2 (данные копятся: `releases.first_seen_at`).

## Наблюдения по реальным заголовкам (`tests/fixtures/releases/hub-corpus.tsv`)

- В раздаче обычно **несколько озвучек**: «Dub (Red Head Sound) + 6 x MVO (HDrezka Studio, AlexFilm, …)». У релиза — список озвучек, не одна студия.
- Почти всё — **паки сезона**; отдельные серии — LostFilm (на каждое качество свой торрент). Выходящий сезон на RuTracker — обновляемый пак «S2E1-5 of 10».
- Форматы по трекерам:
  - RuTracker: `Название / S2E1-10 of 10 [2025, WEB-DL 1080p] Dub (X) + 6 x MVO (A, B) + Original + Sub (Rus, Eng)`; аниме: `(S2) / Romaji / English [TV] [E10 of 12] [RUS(ext), JAP+Sub]`.
  - Kinozal: `Название - S2E1-10 - 2025  DUB (X), MVO (A, B), Sub HEVC WEBDL 1080p - RUSSIAN`; `S1-2E1-19` — несколько сезонов.
  - LostFilm: `Название - S5E8 - Название серии - rus 1080p WEBDL (LostFilm)`; `Название - S2 - rus WEBDL (LostFilm)` — сезон.
  - RUDUB: `Рус (Eng)S2E01-10 (HD 1080p WEBRip) Полный S2`.
  - Anilibria: `Рус 2 / E01-E10 Romaji 2nd Season - AniLiberty.TOP [WEB-DL 1080p]`.
  - AniDUB: `Romaji  S02E01-E10 [RUS] [HDTV 1080p]`.
- Короткие варианты написания («LF», «RHS», «JAM») нельзя искать подстрокой — только целым словом.

## Решения

### Данные

`trackers`: `id`, `source_id` (каскад), `indexer_id` (id у источника, напр. `rutracker`), `name` (как показывает источник), `kind`: `series|anime|both|unknown`
(из категорий трекера), `role`: `primary|backup`, `last_ok_at`, `last_error`, `last_error_at`. Уникально `(source_id, indexer_id)`.
Роль: трекер одного `indexer_id` в нескольких источниках — основной у источника, добавленного раньше; пользователь может поменять.

`releases`: `id`, `title_id` (каскад), `source_id`, `tracker_id`, `title` (исходный заголовок), `attrs` (JSON: все `torznab:attr` + категории),
`size` (байты), `seeders`, `peers`, `infohash` (может быть null), `download_enc` (ссылка на .torrent, зашифрована — в ней ключ источника),
`magnet` (может быть null), `details_url`, `published_at`, `first_seen_at`, `last_seen_at`, `parsed` (JSON `ParsedRelease`), `match` (JSON `MatchResult`).
Уникально по `infohash`, иначе по `(tracker_id, title, size)` — повторный поиск обновляет `last_seen_at`, сиды, ссылку.

`release_rules`: `id`, `title_id`, `tracker_id` (может быть null — любой трекер), `pattern` (нормализованная «основа» заголовка — текст до первых `/`, ` - S`, `(`, `[`),
`verdict`: `match|reject`, `created_at`. Совпадение правила: тот же трекер (или null) и та же основа. `match` → оценка совпадения 1; `reject` → 0 и причина «В чёрном списке».

Профиль (правка 1b): ожидание позиции = «через N дней после эфира» (решение владельца); `validateProfile` требует неубывания ожиданий сверху вниз
(«Ожидание не может быть меньше, чем у позиции выше»); подпись в редакторе — «через N дн».

### Torznab

- Запросы: `GET {url}?t=search&q=…&cat=5000,5070&apikey=…` (`url` — как введён: напр. `http://jackett:9117/api/v2.0/indexers/all/results/torznab/`).
  Ответ — RSS: `item` → `title`, `guid`, `link` (ссылка на .torrent), `comments` (страница раздачи), `pubDate`, `size`, `category`,
  `jackettindexer[@id]` (Jackett) или `torznab:attr name="indexer"`/`prowlarrindexer` (Prowlarr), `torznab:attr` (`seeders`, `peers`, `infohash`, `magneturl`, `category`…).
- Список трекеров: `t=indexers&configured=true`; если источник его не поддерживает — трекеры собираются из результатов поиска.
- Разбор XML — `fast-xml-parser`. Ошибка Torznab `<error code=… description=…>` → понятная ошибка источника.
- Таймаут — `sources.timeout_ms` (по умолчанию 15 с).

### Поиск по сериалу

`searchTitle(db, titleId, opts)`:
1. Запросы — уникальные (без учёта регистра и знаков) названия: `nameRu`, `nameOriginal` (если латиница/кириллица), `altNames`; для аниме — сначала латиница. Не больше 4 запросов.
   Сезон и серию в запрос не добавляем: русские трекеры ищут по названию, сезон и серия отфильтровываются разбором.
2. Все включённые источники × все запросы — параллельно (не больше 4 одновременно на источник); ошибка источника → статус источника, остальное продолжается.
3. Объединение: дедупликация по `infohash`, иначе `(трекер, заголовок, размер)`; если трекер пришёл и от основного, и от запасного источника, а основной ответил без ошибки — запись запасного отбрасывается.
4. Разбор, оценка совпадения, запись в `releases` (upsert).
5. Результат: список релизов сериала + статусы источников/трекеров (сколько найдено, ошибка, время ответа).

### Разбор заголовка (`parseRelease(title, attrs, trackerName, studios)`)

```ts
type ParsedRelease = {
  base: string;                 // «основа» для правил и сравнения названий
  names: string[];              // названия из заголовка (части через «/», текст в скобках у RUDUB и т.п.)
  year: number | null;
  seasons: number[];            // пусто — не указан
  episodes: { from: number; to: number } | null;   // null — весь сезон / не указаны
  totalInSeason: number | null; // «of 10»
  absolute: boolean;            // E01-E28 без сезона (аниме) — сквозная нумерация
  pack: boolean;                // больше одной серии или целый сезон
  resolution: 2160 | 1080 | 720 | 576 | 480 | null;
  source: 'webdl' | 'webrip' | 'bdrip' | 'remux' | 'hdtv' | 'dvd' | 'cam' | null;
  hdr: boolean; dv: boolean; screener: boolean;
  dubs: { kind: 'dub' | 'mvo' | 'dvo' | 'vo' | 'avo'; studioId: number | null; label: string; by: 'tracker' | 'title' | 'tag' | 'none' }[];
  original: boolean; subs: boolean;
};
```

- Сезон/серии: `S02E05`, `S2E1-10`, `S1-2E1-19` (сезоны 1–2), `S02E01-E10`, `S2E01-10`, `S5E0-8`, `S2 ` (сезон целиком), `(S2)`, `Сезон: 2`, `Серии: 1-4 из 8`, `[E10 of 12]`, `E01-E28`, `Полный S2`, «2nd Season» (аниме → сезон 2).
- Качество: `2160p|4K|UHD` → 2160; `1080p|1080i` → 1080; `720p` → 720; `576p`, `480p`; источник по `WEB-DL|WEBDL`, `WEBRip`, `BDRip|BluRay|Blu-Ray`, `Remux|BDRemux`, `HDTV|HDTVRip`, `DVDRip`, экранки — `CAMRip|TS|TC|Telesync|Telecine|экранка`; HDR — `HDR|HDR10|HDR10+`, DV — `Dolby Vision|DV|DoVi`.
  Теги Jackett дополняют то, чего нет в заголовке.
- Озвучки:
  1. «Свой трекер» студии (`studios.trackers` ⊇ имя/id трекера) → озвучка этой студии, `by: 'tracker'`.
  2. Группы `Dub|DUB|MVO|DVO|VO|AVO` с перечнем в скобках: каждая позиция — озвучка указанного типа; студия — поиск по словарю **целыми токенами** (нормализованное имя/вариант совпадает с нормализованной позицией), `by: 'title'`; не нашлась — `studioId: null`, `label` — как в заголовке.
  3. Тип без перечня («DUB», «3 x MVO», «VO») — озвучка без студии (`studioId: null`, `by: 'none'`).
  4. Подписи в заголовке вне групп (`AniLiberty.TOP`, `(LostFilm)` у LostFilm) — по словарю, `by: 'title'`.
  5. Теги Jackett «дубляж/многоголосый/…» — добавляют тип, если в заголовке его нет (`by: 'tag'`).
  `Original|Оригинал` → `original`; `Sub|Субтитры|JAP+Sub|RUS(ext)` → `subs`.

### Сквозная нумерация аниме

`absoluteToSeason(n, seasons)` по числу серий сезонов из TMDB (без спецвыпусков): серия 37 при сезонах 25 и 12 → S2E12. Применяется, когда `absolute = true`
и в заголовке нет признака сезона, а у сериала больше одного сезона и `n` больше числа серий первого.

### Тот ли сериал (`matchRelease`)

Оценка 0…1 = взвешенная сумма:
- название (0,6): лучшее сходство (коэффициент Дайса по биграммам нормализованных строк) любого `names` релиза с любым названием сериала; точное совпадение основы — 1;
- год (0,15): совпадает ±1 с годом сериала или с годом сезона из заголовка — 1; не указан — 0,5; иначе 0;
- сезон/серии (0,15): все сезоны есть у сериала в TMDB и номера серий не больше числа серий — 1; сезона нет — 0;
- размер (0,1): размер на серию в разумных пределах (0,1–15 ГБ для 2160p, 0,1–8 для 1080p, 0,05–4 для остального) — 1, иначе 0.
Правило `match` → 1, `reject` → 0. Пороги: ≥ 0,8 — «подходит», 0,5–0,8 — «сомнительно», < 0,5 — «не тот сериал».

### Оценка для подписки (`evaluateReleases(releases, title, subscription, target, today)`)

`target` — серия `{season, episode}` или сезон `{season}` (ручной поиск сезона). Для каждой раздачи — вердикт:
- отказы (по порядку проверки): «Не тот сериал» / «Сомнительное совпадение» / «В чёрном списке»; «Не та серия» (не содержит цели); «Экранка»;
  «Ниже {target}p» (если `allowLower` — только ниже следующего уровня не отказ, а штраф); «Больше N ГБ» (на серию); «Нет сидов»;
  «Не в профиле озвучки» (ни одна озвучка раздачи не совпала с позициями профиля, «Любая» — любая русская озвучка, «Оригинал» — `original && subs`);
  «Неизвестная студия» (есть озвучка без студии, и профиль не содержит «Любая» — нужен ответ пользователя).
- ожидание: позиция профиля, которой соответствует раздача, открыта, если `air_date + waitDays ≤ today` (для сезона — по последней нужной серии); иначе «Рано: ждём {выше стоящую} до {дата}».
- лучший — среди прошедших: меньший индекс позиции профиля; отдельная серия лучше пака; разрешение — точное совпадение лучше, выше лучше ниже; HDR при `preferHdr`; больше сидов; меньший размер.
  Подпись: «Лучший · {N}-я по приоритету».
- `finalCheck(release)` — место для Laya (фаза 4), пока возвращает «да».

### Экраны

**«Ручной поиск»** (`/search/[tmdbId]?s=2&e=5`; без `e` — сезон): заголовок «Ручной поиск», подзаголовок «Название · S02E05»,
полоса статусов источников («Jackett · 412 · 1,2 с», ошибка — danger), таблица по макету: релиз (моно 12 px, в одну строку с переносом), трекер,
озвучки (имена через запятую; нераспознанная — accent с «?»), как распознана, качество, размер, сиды (0 — danger), вердикт (лучший — accent и подсветка строки,
отказ — `faint` и строка с `opacity-60`). Действия в строке: «Назначить студию» (у нераспознанной: выбрать студию из словаря → вариант написания добавляется в словарь;
или «Новая студия»), «Не тот сериал» / «Это он» (правило), «Скачать» — неактивна до 1d.
Кнопка «Ручной поиск» в карточке сериала (рядом с «Обновить из TMDB») и у каждой серии в таблице (иконка лупы).
Телефон — строки карточками.

**«Настройки → Источники»** (раздел уже есть с карточкой TMDB): карточки источников (точка статуса, имя, адрес моно, «N трекеров · M мс», состояние),
«+ Добавить источник» (модалка: название, адрес Torznab, API-ключ, таймаут; «Проверить и сохранить» — `t=caps` + `t=indexers`), правка/удаление;
таблица трекеров по макету: Трекер, Контент, Основной, Запасной, Статус; основной меняется выбором в строке.
Источники, добавленные мастером, тут же видны.

## Ошибки и крайние случаи

- Все источники недоступны — поиск возвращает пустой список и ошибки источников; в UI — «Ни один источник не ответил».
- Заголовок обрезан или без сезона/серий — `seasons: []`, `episodes: null`; для цели-серии такой релиз — «Не та серия» (кроме случая одного сезона у сериала: тогда считается сезон 1).
- Раздача на несколько сезонов (`S1-2E1-19`) — содержит цель, если сезон входит в диапазон; серии в многосезонном диапазоне не проверяются по номерам.
- `infohash` нет (часть трекеров) — дедупликация по трекеру+заголовку+размеру.
- Ссылка на .torrent хранится зашифрованной; в логах — `redactUrl`.

## Тесты

- Парсер: каждая строка корпуса — ожидаемые сезоны/серии/пак/качество/озвучки (таблица в `tests/unit/parse-corpus.test.ts`), плюс синтетические случаи из spec §3 («Сезон: 2 / Серии: 1-4 из 8», экранки, HDR/DV).
- Распознавание озвучек: свой трекер, перечень в скобках, токены vs подстрока («LF» не находится в «WOLF»), нераспознанная студия.
- Сквозная нумерация.
- Torznab: разбор сохранённого XML Jackett (поиск и `t=indexers`), ошибки `<error>`, таймаут.
- Поиск: параллельность, падение одного источника, дедупликация, основной/запасной.
- Совпадение: веса, правила, пороги.
- Оценка: каждый вердикт, ожидание по дате эфира, выбор лучшего.
- E2E: заглушка Jackett (`tests/e2e/jackett-stub.mjs`) → источник в настройках → «Ручной поиск» по «Игре престолов» показывает лучший релиз и причины отказов → «Назначить студию».
