# Сканирование медиатеки — дизайн

Дата: 2026-10-16. Версия: 2.7.

## Зачем

В медиатеке лежит много того, что попало туда мимо Dublyarr:
- сериалы в чужой структуре (`BEEF/Season 01/BEEF - S01E01 - WEB-DL 2160p TVShows.mkv`);
- раздачи как скачались (`Black.Bird.S01.1080p…EniaHD/` с `.archos.nfo` и обложками, `Task.S01.WEB-DLRip.LF/` с `.avi` и `.srt`);
- фильмы файлом в корне (`Happy.Gilmore.1996.BDREMUX.mkv`).

Dublyarr про них не знает: не учитывает в «Хранилище» и правилах хранения, может скачать серию второй раз, а папки лежат не по шаблону.

Нужно: по кнопке найти такое, показать окно с распознанным, по подтверждению взять в Dublyarr и разложить по шаблону.

## Решения владельца

- Только по кнопке, без расписания.
- Сканируются и сериалы, и фильмы.
- Для сериала в окне выбор: «С подпиской» или «Только файлы».
- Файл, который раздаётся в qBittorrent, становится жёсткой ссылкой; остальные перемещаются.
- Галочка «Пересобрать как при импорте» у каждой позиции, по умолчанию выключена.

## Как выглядит

### Блок «Медиатека» в правой колонке «Хранилища»

- Кнопка «Сканировать».
- Под ней — последний результат: «Найдено 14 · 2 часа назад», кнопка «Открыть».
- Во время работы — «Сканирую… 6 из 21» или «Добавляю… 3 из 9».
- После добавления — итог: «Добавлено 8 · пропущено 1 · ошибка 1». Пропуски и ошибки — с причиной.

### Окно (`ui/Modal`; на телефоне шторка)

Для каждой позиции:
- постер, название по TMDB, год, тип (сериал / аниме / фильм);
- папка-источник, число видеофайлов, общий размер;
- для сериала — какие серии распознаны («Season 01: 1–10»), нераспознанные файлы — отдельной строкой;
- серии, у которых в Dublyarr уже есть файл, — с пометкой «уже есть», по умолчанию не добавляются;
- «Это не он» → поиск по TMDB прямо в окне (тот же клиент, что «Поиск и тренды»);
- для сериала — «С подпиской» / «Только файлы»;
- «Пересобрать как при импорте» — выключено по умолчанию;
- пример нового пути: `Silo (2023)/Season 03/Silo S03E01 [LostFilm 1080p].mkv`;
- галочка «добавить»: уверенно распознанное отмечено, сомнительное — нет.

Ниже — раздел «Не распознано»: что нашлось и почему не подходит («Нет видео», «Не нашёлся в TMDB», «Нет номеров серий»). Действий в нём нет.

Внизу — итог: «Добавить 9 · 412 ГБ · из них раздаются 3 — станут жёсткими ссылками». Если отмечена пересборка, к итогу добавляется «оригиналы после пересборки удаляются (кроме раздающихся)». Кнопка «Добавить».

## Как работает

### Сканирование — задача `media.scan` (`src/lib/media-scan/scan.ts`)

1. **Обход.** Корень медиатеки (`paths.media`) и папка фильмов, если задана.
   - Пропускаются `.dublyarr-old`, `.dublyarr-tmp` и служебное (`isJunk` из `empty-dirs.ts`).
   - Видео — по расширениям `.mkv .mp4 .avi .m4v .ts .m2ts .webm .mov .wmv .flv`. Видеофайлы, которые уже есть в `episode_files`, пропускаются.
2. **Группировка.** Позиция — папка верхнего уровня; видеофайл в корне — отдельная позиция.
   - Папка, где все видео уже в Dublyarr, — не позиция.
   - Папка Dublyarr с новыми файлами (сериал есть в библиотеке, а файлов в базе нет) — позиция этого же сериала: TMDB уже известен.
3. **Распознавание** (`src/lib/media-scan/recognize.ts`, чистое, кроме поиска TMDB):
   - названия, год, сезон/серии — `parseRelease` по имени папки и каждого файла. Имя файла главнее, папка подсказывает название и сезон;
   - тип: есть сезон/серии или папки `Season NN` — сериал; один видеофайл без номеров — фильм;
   - TMDB — поиск по названиям (ru/латиница) с годом. Кандидат — лучший по `match.ts` (название + год + число сезонов);
   - уверенно — счёт ≥ 0,8 (порог «подходит» из `match.ts`); иначе галочка снята;
   - аниме со сквозной нумерацией — через `resolveAbsolute`, как у раздач.
4. **Результат** пишется в `app_settings['mediaScan']`: позиции, файлы, кандидат TMDB, распознанные серии, причины. Окно читает его без повторного сканирования. Новое сканирование результат заменяет.

### Добавление — задача `media.adopt` (`src/lib/media-scan/adopt.ts`)

На вход — отмеченные позиции с выбором пользователя (TMDB id, подписка или файлы, пересборка). Позиции идут по одной; сбой одной не останавливает остальные.

1. **Каталог.** `openTitle` (карточка, сезоны, серии TMDB). Подписка — `subscribe` с профилем по умолчанию по типу.
   - «Только файлы» — `subscriptions.files_only = true` (миграция). Такую подписку пропускают автопоиск, улучшение, «новые сезоны» и проверка паков.
   - Уже подписан — подписка не меняется.
2. **Раздаётся ли.** `getQbit` → торренты, их пути переводятся через `toLocalPath`. Файл раздаётся, если его путь совпадает с файлом живого торрента. qBittorrent не настроен или недоступен — считается «раздаётся», то есть жёсткая ссылка: ничего не сломать.
3. **Каждый видеофайл:**
   - ffprobe → разрешение, HDR, длительность, дорожки;
   - студия — `classifyAudio` по словарю, иначе из имени файла (`parseRelease`). Нет — без студии в имени;
   - проверка «та ли серия» по длительности (`checks.ts`) — не прошла: файл пропускается с причиной;
   - путь — `renderTemplate` (шаблон сериалов или фильмов);
   - по новому пути уже есть файл — пропуск «Уже есть», никакой перезаписи.
   - **Без пересборки:** раздаётся — жёсткая ссылка (при `EXDEV` — копия, как в `importer.ts`), иначе — `rename`.
   - **С пересборкой:** `processFile` как при импорте → полная копия `.mkv` в медиатеке. После проверки результата (ffprobe читается, длительность ±2 %) — оригинал удаляется, если не раздаётся.
   - Запись в `episode_files` (`processed`, `resolution`, `hdr`, `duration`, `tracks`). Разметку заставок сбрасывает так же, как импорт.
4. **Сопутствующие файлы.** `.srt .ass .ssa .sub .idx .mka` с тем же началом имени, что у видео (`Task.S01E01…avi` → `Task.S01E01….forced.rus.srt`), идут рядом с видео под новым именем с сохранённым хвостом (`… [LostFilm 720p].forced.rus.srt`). Способ переноса — тот же, что у видео. `.nfo` и обложки не переносятся.
5. **Старая папка.** `pruneUp` от папки файла до корня. В ней осталось не только служебное — папка остаётся, в отчёт идёт строка «В `BEEF/` осталось 3 файла».
6. **Итог** — в `app_settings['mediaScan'].last`: добавлено, пропущено и ошибки с причинами. Telegram — одна сводка «скачано» (`notify-events`), не по серии на каждый файл.

### Защита

- Пути — только внутри `paths.media` и папки фильмов (`inside` из `retention.ts`). Чужой путь — отказ позиции.
- Ни одна существующая запись не перезаписывается и не удаляется, кроме одного случая: оригинал после успешной пересборки, только когда пользователь отметил пересборку и нажал «Добавить». В окне это сказано прямо.
- Каждое действие — в журнал (область `storage`): что, откуда, куда, как (ссылка / перемещение / пересборка).
- Права: сканирование и добавление — только админ или право `storage`. Создание подписки дополнительно требует права `subscribe`.

## Интерфейс и API

- `src/app/(app)/storage/MediaScanCard.tsx` — блок; `MediaScanDialog.tsx` — окно; `actions.ts` — `startMediaScanAction`, `adoptMediaAction`, `mediaScanStateAction` (опрос раз в 2 с, пока идёт задача — как `useFound`).
- Поиск TMDB в окне — тот же, что `/search` (`searchTitles`).
- API: `GET /api/v1/media/scan` (результат и состояние), `POST /api/v1/media/scan` (запуск), `POST /api/v1/media/adopt` (выбор как в окне).
- «Библиотека»: у подписки «только файлы» — пометка. На странице сериала — «Включить подписку» (снимает `files_only`).

## Проверка

- Unit, фикстуры по реальным именам из медиатеки владельца:
  - группировка и распознавание: `BEEF/Season 01`, `Black.Bird.S01…EniaHD`, `Task.S01.WEB-DLRip.LF` (`.avi` + `.srt`), `참교육/Season 01`, `Silo/Season 03`, `Family Guy/Season 23,24`, фильмы в корне, папка Dublyarr с новыми файлами, папка без видео;
  - перенос во временной папке: раздаётся → ссылка (inode тот же), иначе → перемещение; сопутствующие `.srt`; «Уже есть» — без перезаписи; путь вне медиатеки — отказ; старая папка с `.nfo` остаётся, со служебным — уходит;
  - пересборка: оригинал удаляется, только если не раздаётся и результат проверен;
  - `files_only` пропускается автопоиском, улучшением, новыми сезонами, проверкой паков;
  - права (`guards.test.ts`).
- e2e: на заглушках TMDB и qBittorrent — разложить в медиатеку чужую папку и фильм, «Сканировать» → окно → «Добавить» → файлы по шаблону, сериал в «Библиотеке» с пометкой «только файлы».

## Не делаем сейчас

- Сканирование по расписанию и строку в «Требует внимания».
- Перенос `.nfo` и обложек.
- Разбор архивов и образов (`.iso`, `.rar`).
