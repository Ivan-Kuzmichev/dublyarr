# Фаза 1d «Загрузки»: дизайн

Последняя часть фазы 1 (1a каталог → 1b подписки → 1c поиск → **1d загрузки**). После неё Dublyarr заменяет текущую версию.
Источник правды по поведению — `docs/spec.md` §4–6; здесь — как делаем.

## Цель

Сам находить нужные серии подписок, качать лучшие раздачи через qBittorrent (отдельная серия или нужный файл из пака),
по завершении класть файл в медиатеку по шаблону имени и показывать всё это на «Сегодня», в «Календаре», «Активности» и карточке сериала.

## Что входит

- Клиент qBittorrent WebAPI v2 (v4 и v5), разбор `.torrent` (infohash, файлы).
- Настройки «Загрузка и папки»: qBittorrent, пути (загрузки глазами qBittorrent ↔ глазами Dublyarr, медиатека), шаблон имени, проверка жёстких ссылок.
- Таблицы `downloads`, `episode_files`; состояние серии.
- Решение «что качать для серии» (`planEpisode`) и для сезона целиком после финала.
- Воркер: поиск по подпискам (раз в час + «Искать сейчас»), синхронизация загрузок (раз в минуту), импорт.
- Экраны: «Сегодня», «Календарь», «Активность» (очередь), колонка «Статус» в карточке сериала, «Скачать» в ручном поиске.

## Что не входит (фаза 2+)

- Обновление пака по смене хэша топика, автозамена застрявшей раздачи, замена на приоритетную озвучку и улучшение качества.
- Прогноз озвучки, статистика студий, настройки расписания поиска и скорости, уборка в qBittorrent, Telegram.
- Пересборка mkv, внешние дорожки, ffprobe (фаза 3): в медиатеку идёт исходный видеофайл.

## Решения

### Пути

Настройка `paths` (расширяется): `qbitDownloads` — папка загрузок так, как её видит qBittorrent (например `/downloads`); `downloads` — та же папка изнутри Dublyarr
(например `/storage/downloads`); `media` — медиатека. Путь файла от qBittorrent (`content_path`/`save_path` + имя файла) переводится заменой префикса
`qbitDownloads` → `downloads`. Если префикс не совпал — ошибка загрузки «Путь qBittorrent вне папки загрузок: …».
Раздачи Dublyarr сохраняются в `{qbitDownloads}/dublyarr` с категорией `dublyarr`.

Импорт: жёсткая ссылка (`fs.link`); при `EXDEV`/`EPERM`/`ENOTSUP` — копия (`fs.copyFile`, затем переименование из временного имени). В настройках —
«Проверить»: пробная ссылка между `downloads` и `media` → «Жёсткие ссылки работают» / «Будет копирование: папки на разных томах».
Уже существующий файл с тем же путём заменяется (импорт идемпотентен).

### Шаблон имени

По умолчанию (spec §6): `{Название} ({Год})/Season {С}/{Название} S{С}E{Е} [{Студия} {Качество}]` + расширение исходного файла.
Переменные: `{Название}` — русское название, `{Оригинал}`, `{Год}`, `{С}`/`{Е}` — две цифры, `{Студия}` — студия раздачи (из позиции профиля или первая распознанная, иначе «Оригинал»),
`{Качество}` — «2160p»/«1080p»/…, пусто — без. Запрещённые в именах символы (`/\:*?"<>|`) заменяются, двойные пробелы и пустые `[]` убираются, имя части ≤ 120 символов.

### qBittorrent

- Вход `POST /api/v2/auth/login`, cookie `SID`; при 403 на любом запросе — повторный вход один раз.
- Версия `GET /api/v2/app/webapiVersion`: ≥ 2.11 → `torrents/start|stop`, иначе `resume|pause`.
- Добавление: `.torrent` скачивает Dublyarr (ссылка из `releases.download_enc`; если ссылки нет — `magnet`), `POST /api/v2/torrents/add` (multipart: `torrents`, `savepath`, `category=dublyarr`, `paused=true`, `stopped=true`, `tags=dublyarr`).
  Хэш — вычисляется из `.torrent` (SHA-1 словаря `info`); для magnet — из `btih`.
- Состояние: `GET /api/v2/torrents/info?category=dublyarr`; файлы: `GET /api/v2/torrents/files?hash=`; приоритеты: `POST /api/v2/torrents/filePrio` (`id` — индексы через `|`).
- Удаление из клиента — `torrents/delete` с `deleteFiles=false`. Чужие торренты (не категории `dublyarr`) не трогаются.

### Данные

`downloads`: `id`, `hash` (уникальный), `title_id`, `release_id` (set null), `season`, `kind`: `episode|pack|season`, `episodes` (JSON `{season,number}[]` — что из неё нужно),
`state`: `adding|downloading|paused|stalled|completed|imported|error|removed`, `progress` (0…1), `dl_speed`, `eta`, `size`, `name`, `content_path`, `studio_label`, `resolution`,
`added_at`, `completed_at`, `imported_at`, `last_seeded_at` (последний раз, когда были сиды), `last_error`.
`episode_files`: `id`, `title_id`, `season`, `number`, `path` (относительно медиатеки), `size`, `download_id` (set null), `studio_label`, `resolution`, `method`: `hardlink|copy`, `imported_at`. Уникально `(title_id, season, number)`.

`wanted_state`: `title_id`, `season`, `number`, `state`: `waiting|missing|ask`, `reason`, `until` (дата открытия, для `waiting`), `checked_at`. Уникально `(title_id, season, number)`; запись удаляется, когда серия качается или скачана.

Состояние серии подписки (вычисляется): `downloaded` (есть файл), `downloading` (есть активная загрузка с ней), `waiting` (вышла, есть раздачи, но позиция ещё не открылась — с датой),
`missing` (вышла, подходящих раздач нет / нужен ответ), `upcoming` (не вышла), `skipped` (вне «что скачать»).

### Что качать для серии (`planEpisode`)

Вход: нужная серия, вердикты 1c для неё, активные загрузки сериала. По порядку (spec §4):
1. Серия уже есть в загрузке-паке этого сезона (файл найден в списке файлов) → `enable-file` (поставить файлу приоритет 1).
2. Лучшая раздача — отдельная серия → `add` (весь торрент).
3. Лучшая — пак → `add-pack` (добавить на паузе → приоритет 0 всем, кроме файлов этой серии → запуск).
4. Нет лучшей: есть `wait` → `wait` (дата открытия ближайшей позиции); есть `ask` → `ask`; иначе → `none`.
Несколько нужных серий одного сезона, которые берутся из одного пака, — одна загрузка с несколькими файлами.

«Сезон целиком после финала»: сезон «закончен», когда последняя серия сезона по TMDB вышла (`air_date ≤ сегодня`) и у сезона нет серий без даты. До этого серии сезона — `waiting` («ждём финал»).
После — цель «сезон»: лучшая раздача, содержащая все серии сезона (пак без диапазона или `1…N`), качается целиком (`kind: season`).

### Сопоставление файлов серии

`episodeFromFilename(name, season)` → номер серии: `S01E03`, `1x03`, `E03`, `Серия 3`, `03 серия`, ` - 03 `, `[03]`, `03.` в начале имени; без разрешений (`1080`), годов, кодеков (`x265`, `H.264`).
Видео — `.mkv .mp4 .avi .m4v .ts .webm`. Торрент из одного видеофайла для одной серии — этот файл без разбора имени.

### Воркер

- `subscriptions.search` — раз в час (`scheduleEvery`) и по кнопке «Искать сейчас»: для каждой подписки — нужные серии (`wantedEpisodes`) минус скачанные и качающиеся;
  если таких нет — пропуск; иначе один `searchTitle`, затем `evaluateReleases`/`planEpisode` по каждой серии, действия в qBittorrent. Ошибка одной подписки не мешает остальным.
  Итог по каждой нужной серии (ждём до даты / нет раздач / нужен ответ) сохраняется в `wanted_state` — его показывают экраны.
- `downloads.sync` — раз в минуту: состояние торрентов категории `dublyarr` → `downloads`; завершённые (прогресс 1 по нужным файлам) → импорт нужных файлов → `episode_files`, `state = imported`.
  Нет сидов больше суток у незавершённой → `stalled`. Торрент исчез из клиента → `removed`. qBittorrent недоступен — статус сервиса «qBittorrent · не отвечает», загрузки не трогаются.
- Статусы в боковой панели: «qBittorrent · N ↓ / не отвечает / не настроен».

### Экраны

- **«Сегодня»** (`Main.dc.html`, `Mobile.dc.html`): «Новые серии» (импортированы за 3 дня или качаются), «Ждём озвучку» (серии `waiting`: «Оригинал 29 сент», «{позиция} — с 3 окт», текст причины;
  полоски прогноза из макета — фаза 2), «Загрузки» (активные, прогресс, скорость, осталось), «Неделя» (серии подписок с эфиром на 7 дней вперёд). Блок «Хранилище» — фаза 3 (скрыт).
- **«Календарь»** (`Calendar.dc.html`, `MobileCalendar.dc.html`): неделя пн–вс, переключение недель; события — серии подписок по дате эфира: «скачано» (светлая заливка, студия · качество),
  «оригинал» (серая рамка, ещё не скачано), сегодня подсвечено. Прогноз (пунктир) — фаза 2.
- **«Активность»** (`Activity.dc.html`, левая часть; `MobileActivity.dc.html`): очередь загрузок — название · серия, исходное имя раздачи (моно), прогресс, состояние («Качается · 64 % · 4 мин»,
  «Из пака: 1 файл из 3», «Нет сидов 6 ч», «Ошибка: …»), скорость; «Пауза / Продолжить», «Убрать из клиента» (без удаления файлов). Внизу — «Искать сейчас».
- **Карточка сериала**: колонка «Статус» (Скачана · студия · качество · размер / Качается N % / Ждём озвучку · с 3 окт / Нужна / через N дн) и подстрока файла.
- **Ручной поиск**: «Скачать» у раздач с вердиктом `best/ok` (для цели-серии — по `planEpisode` с выбранной раздачей; для сезона — пак целиком).
- **«Настройки → Загрузка и папки»** (`Settings.dc.html`, раздел «Загрузка»): qBittorrent (адрес, логин, пароль, «Проверить» — версия), пути (три поля + «Проверить»: запись, жёсткие ссылки),
  шаблон имени с примером («Игра престолов (2011)/Season 01/Игра престолов S01E03 [LostFilm 1080p].mkv»).

## Ошибки и крайние случаи

- qBittorrent не настроен — поиск по подпискам находит, но не качает; на «Сегодня» — «Подключите qBittorrent в настройках».
- `.torrent` не скачался (ссылка протухла) — пробуем `magnet`; нет и его — загрузка `error` «Не удалось получить торрент», в следующий проход берётся следующая по рейтингу раздача (эта помечается).
- В паке не нашлось файла серии — `error` «В раздаче нет файла S01E05», раздача помечается, берётся следующая.
- Импорт: нет места/прав — `error`, файл в загрузках остаётся, повтор при следующей синхронизации.
- Торрент удалили в клиенте руками — `removed`, серия снова «нужна».
- Одна серия в двух загрузках не появляется: перед `add` проверяются активные загрузки сериала.

## Тесты

- Unit: разбор `.torrent` (infohash, файлы, однофайловый/многофайловый), magnet → хэш; клиент qBittorrent на фиктивном `fetch` (вход, повторный вход при 403, v4/v5 команды, add multipart, files, filePrio);
  перевод путей; шаблон имени; `episodeFromFilename` на реальных именах файлов (LostFilm, RuTracker-паки, AniLibria, RUDUB); `planEpisode` (все ветки); «сезон закончен»; импорт (ссылка/копия, повтор);
  синхронизация (состояния, завершение → импорт, stalled, removed); данные «Сегодня»/«Календаря».
- E2E: заглушка qBittorrent (`tests/e2e/qbit-stub.mjs`, хранит торренты в памяти, «докачивает» по запросу) → настройки → подписка → «Искать сейчас» → загрузка в «Активности» → завершение → файл в медиатеке, «Скачана» в карточке, «Новые серии» на «Сегодня».
