# Фаза 1b «Подписки и студии»: дизайн

Вторая часть фазы 1 (1a каталог → **1b подписки и студии** → 1c поиск и разбор → 1d загрузки).
Источник правды по поведению — `docs/spec.md` §1; здесь — как делаем.

## Цель

Пользователь подписывается на сериал с профилем озвучек и качества, видит подписки в «Библиотеке», правит профили по умолчанию
и словарь студий. На этих данных 1c ищет раздачи (`wantedEpisodes`, порядок озвучек, словарь), 1d их качает.

## Что входит

- Таблицы `studios`, `subscriptions`; начальный словарь студий.
- Профили по умолчанию (сериалы, аниме) в `app_settings`.
- Окно подписки (desktop — модалка по `Subscribe.dc.html`, телефон — шторка по `MobileSubscribe.dc.html`), блок «Подписка» в карточке сериала.
- «Библиотека» (`Library.dc.html`, `MobileLibrary.dc.html`) — подписанные сериалы.
- «Настройки → Подписки и студии» — профили по умолчанию и словарь.
- `wantedEpisodes` — какие вышедшие серии нужны по подписке.

## Что не входит

- Колонки «серий у студии / задержка / макс. качество» в окне подписки — по раздачам (1c) и статистике (фаза 2).
- Фильтры библиотеки «Ждут озвучку», «Свежие серии» — 1d.
- Настройки дорожек (spec §6) — фаза 3, вместе с пересборкой mkv.
- Удаление файлов при отписке — фаза 3; сейчас «Отписаться» убирает только подписку.
- Автоподписка на новые сезоны как процесс (spec §11) — фаза 2; флаг в подписке хранится уже сейчас.
- Подтверждение студий, добавленных Laya, — фаза 4 (поле `source` есть).

## Решения

### Словарь студий (`studios`)

- `id`, `name` (каноническое, уникальное без учёта регистра), `aliases` (JSON-массив строк), `kind`: `series` | `anime` | `both`,
  `trackers` (JSON-массив: «своё» имя трекера из Jackett, раздачи с которого — всегда эта студия, напр. `lostfilm`, `anilibria`),
  `source`: `seed` | `manual` | `laya`, `confirmed` (bool), `created_at`.
- Имя и варианты написания уникальны во всём словаре (сравнение по нормализованной форме: нижний регистр, `ё→е`, без пробелов, точек, дефисов и подчёркиваний).
- Начальный набор (`source = seed`, `confirmed = true`) засевается один раз (флаг `app_settings['studios.seeded']`) при открытии базы.
  Удалённая пользователем студия из начального набора не возвращается.
- Удалить студию, которая стоит в подписке или профиле по умолчанию, нельзя: «Студия используется в N подписках».

### Профиль и подписка

Профиль (он же настройки подписки):

```ts
type DubPosition =
  | { kind: 'studio'; studioId: number; waitDays: number }
  | { kind: 'any'; waitDays: number }        // «Любая»
  | { kind: 'original'; waitDays: number };  // «Оригинал с субтитрами»
type Profile = {
  dubs: DubPosition[];                        // порядок = приоритет; waitDays первой позиции всегда 0
  quality: { target: 720 | 1080 | 2160; allowLower: boolean; preferHdr: boolean; maxSizeGb: number | null };
  scope: { mode: 'all' } | { mode: 'new' } | { mode: 'from'; season: number; episode: number; until: 'season_end' | 'onward' };
  wholeSeasonAfterFinale: boolean;
  replaceWithHigher: boolean;
  autoNextSeason: boolean;
};
```

Правила: хотя бы одна позиция; студия — не больше раза; «Любая» и «Оригинал» — не больше раза каждая; `waitDays` 0…60 (первой — 0);
после «Любой» других позиций нет (выше её приоритета ничто не придёт); `maxSizeGb` — `null` или 0,5…200; `from`: сезон ≥ 1, серия ≥ 1.
Ошибки — на русском, первая найденная.

`subscriptions`: `id`, `title_id` (уникальный, каскад), `profile` (JSON `Profile`), `subscribed_at` (мс), `updated_at`.
Одна подписка на сериал. Подписка хранит свою копию профиля; изменение профиля по умолчанию существующие подписки не трогает.

Профили по умолчанию — `app_settings['profile.series']`, `['profile.anime']`. Если не сохранены — встроенные:
- сериалы: LostFilm (0) → HDrezka Studio (2) → Любая (5);
- аниме: AniDUB (0) → AniLibria (2) → Любая (5);
- оба: 2160p, если нет — ниже, предпочитать HDR, без лимита; «только новые серии»; «заменить, когда выйдет выше» — да; «подписаться на новый сезон» — да; «сезон целиком после финала» — нет.
Встроенный профиль ссылается на студии по имени; студии, которой нет в словаре, в профиле нет.

### Какие серии нужны (`wantedEpisodes`)

Только вышедшие (`air_date ≤ сегодня`), без спецвыпусков (сезон 0):
- `all` — все;
- `new` — с `air_date ≥` даты подписки;
- `from` — сезон `S` с серии `E`; при `onward` — и все следующие сезоны.
Серии без даты эфира не нужны. Результат — по сезону и номеру.

### Экраны

**Окно подписки.** Заголовок — название, подзаголовок «Оригинал · год · N сезонов, M серий · статус». Секции:
1. «Озвучки»: студии словаря подходящего типа (`series`/`anime` + `both`), затем «Любая» и «Оригинал с субтитрами». Нажатие добавляет в конец порядка/убирает;
   выбранная строка — номер в янтарном кружке и рамка accent (как в макете); у выбранных, кроме первой, — регулятор «ждать N дн» (−/+).
   Поле фильтра по имени, если студий больше 8.
2. «Качество»: сегменты 720p/1080p/2160p; «Если {target} нет — брать ниже»; «Предпочитать HDR / Dolby Vision»; «Не больше N ГБ на серию» (выключатель + число).
3. «Что скачать»: радио «Все сезоны / Только новые серии / Начиная с серии»; для последнего — регуляторы сезона и серии и сегменты «до конца сезона / и дальше».
   «Качать сезон целиком после финала» (с пояснением из макета).
4. «Правила»: «Заменить, когда выйдет озвучка выше по приоритету», «Подписаться на новый сезон, когда его объявят».
Внизу — строка-сводка (`describeProfile`), «Отмена», «Подписаться» (при правке — «Сохранить», и слева «Отписаться» — destructive-ghost, с подтверждением).
Ошибки проверки — над кнопками.

**Карточка сериала.** Кнопка «Подписаться» открывает окно; при подписке — «Подписка» (secondary, открывает то же окно в режиме правки).
Справа от таблицы серий (desktop; на телефоне — под hero) блок «Подписка · активна» по макету: список порядка «1 LostFilm сразу / 2 HDrezka если нет 2 дня…»,
строки правил (включённые — accent-точка, выключенные — dim): качество, что скачать, три флага.

**Библиотека** (`/library`). Заголовок «Библиотека» и число. Фильтры-чипы «Все · N / В эфире · N / Завершены · N» (по статусу TMDB: `returning|in_production|planned` / `ended|canceled`).
Сетка карточек как в макете: постер, название, строка «4K · LostFilm → HDrezka», строка состояния: «S02E05 · 7 окт» (ближайшая невышедшая серия), «Завершён», «Новых серий пока не объявлено».
Сортировка: сначала с ближайшей датой серии, потом по названию. Пусто — «Библиотека пуста. Найдите сериал в «Поиске и трендах» и подпишитесь.»

**Настройки → Подписки и студии** (`/settings/studios`). Две карточки «Сериалы» и «Аниме» с цепочкой озвучек и качеством (как в макете), кнопка «Изменить» открывает то же окно (режим «профиль по умолчанию»).
Таблица «Словарь студий · N»: студия, варианты написания (моно), тип, свой трекер, кто добавил; «+ Студия» и правка строки в модалке: имя, варианты (через запятую), тип (сегменты), свои трекеры (через запятую); «Удалить».

## Ошибки и крайние случаи

- Подписка на сериал, которого нет в базе, невозможна (карточка сначала сохраняет его) — действие отвечает «Сериал не найден».
- Удалена студия, стоящая в подписке, — невозможно по правилу выше; если всё же не найдена при показе (старые данные) — позиция показывается как «Студия удалена».
- Словарь пуст (всё удалили) — в окне остаются «Любая» и «Оригинал».
- Одновременная правка подписки из двух вкладок — побеждает последняя запись (единственный пользователь).

## Тесты

- Unit: проверка профиля (все правила), встроенные профили по типу и пропуск отсутствующих студий, подписка/правка/отписка,
  `wantedEpisodes` (все режимы, спецвыпуски, без даты, граница «сегодня»), `describeProfile`, нормализация и поиск студии по варианту,
  уникальность имён/вариантов, запрет удаления используемой студии, одноразовый засев, данные библиотеки (фильтры, ближайшая серия, сортировка).
- E2E (в продолжение `02-catalog`): подписаться на «Игру престолов» с изменённым порядком → карточка показывает блок подписки →
  библиотека показывает сериал → правка качества → отписка → библиотека пуста; в настройках — добавить студию и увидеть её в окне подписки.
