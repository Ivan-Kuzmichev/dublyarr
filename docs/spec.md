# Dublyarr — спецификация

Все решения ниже приняты владельцем. Если макет и этот документ расходятся — прав документ,
расхождение нужно отметить и уточнить.

## 1. Основные сущности

- **Сериал / фильм** — карточка из TMDB (id, названия ru/original/альтернативные, год, тип: сериал, аниме, фильм).
  Тип «аниме» определяется автоматически (жанр «Анимация» + страна Япония), пользователь может поменять вручную.
- **Подписка** — на сериал или фильм:
  - профиль озвучек: упорядоченный список студий + «Любая» + «Оригинал с субтитрами»;
    для каждой следующей позиции — сколько дней ждать предыдущую (запасная озвучка);
  - качество: 720p / 1080p / 2160p, «если нет — брать ниже», предпочитать HDR/DV, лимит размера;
  - что скачать: «все сезоны» | «только новые серии» | «начиная с серии» (сезон + серия, затем «до конца сезона» или «и дальше»);
  - отдельный флаг «качать сезон целиком после финала» (сочетается с любым вариантом выше);
  - «заменить, когда выйдет озвучка выше по приоритету»;
  - «подписаться на новый сезон, когда его объявят»;
  - обработка файла: какие дорожки оставлять (см. §6).
- **Профили по умолчанию** — отдельно для сериалов и для аниме. Подставляются в новую подписку по типу.
- **Студия** (словарь) — каноническое имя, варианты написания, тип (сериалы / аниме / оба),
  «свой трекер» (раздача с трекера X = студия Y, напр. LostFilm, AniLibria/AniLiberty), кто добавил (вручную / Laya, подтверждено или нет).
- **Источник** — Torznab-эндпоинт (Jackett/Prowlarr): название, адрес, ключ. Их несколько.
- **Релиз** — найденная раздача: исходный заголовок и теги (хранить всегда!), трекер, источник, размер, сиды,
  ссылка на топик, хэш, результат разбора (сезон/серии, пак или серия, качество, студия, как распознана), оценка совпадения.

## 2. Поиск и источники

- Опрос всех источников параллельно, свой таймаут у каждого; падение одного не останавливает поиск.
- Дедупликация по infohash, иначе по (трекер, заголовок, размер).
- Если трекер есть в нескольких источниках — ходим через основной, запасной только при сбое основного.
  Пересечения Dublyarr находит сам, спрашивая у каждого источника список трекеров.
- Поиск по всем названиям из TMDB (ru, original, альтернативные; для аниме — романдзи). Фильтр по категориям Torznab.
- `.torrent` скачивает сам Dublyarr и передаёт содержимое в qBittorrent (ссылки Jackett могут быть недоступны клиенту).

## 3. Разбор релиза

Порядок: парсер (заголовок + теги) → словарь студий (варианты написания, «свой трекер») → Laya для непонятного.

- Качество: 2160p/1080p/720p, WEB-DL/BDRip/BDRemux, HDR/DV, экранки (CAMRip, TS, TC).
- Сезон/серии: `S02E05`, «Сезон: 2 / Серии: 1-4 из 8», паки. Для аниме — сквозная нумерация → (сезон, серия) по TMDB.
- **Тот ли это сериал:** оценка совпадения по названиям (нормализация, нечёткое сравнение), году, наличию сезона/серий,
  правдоподобности размера. Пограничные случаи → Laya (да/нет + уверенность). Ниже порога — не качать, спросить пользователя.
- Подтверждённое сочетание (трекер, шаблон названия) → привязка к TMDB id; отклонённое → чёрный список сериала.
- В ручном поиске у каждого релиза показывать: как распознана студия (по трекеру / по названию / по тегу / не распознано),
  оценку совпадения и причину отклонения.

- **Финальная проверка перед загрузкой.** Когда лучшая раздача выбрана, Laya отвечает да/нет:
  «это серия N сезона S сериала X в озвучке Y?» (заголовок, теги, размер, список файлов, если уже известен).
  «Да» с уверенностью от порога — качаем. «Нет» или ниже порога — проверяем следующую по рейтингу, не больше 3;
  ни одна не прошла — вопрос пользователю, отказ сохраняется как размеченный пример.
  Laya недоступна — качаем без финальной проверки.

## 4. Как качается серия

1. **Текущая раздача.** Если сезон уже качался из пака — проверить, не обновился ли топик (хэш сменился).
   Обновился → добавить новый торрент в ту же папку (qBittorrent перепроверит имеющееся), включить только новую серию,
   старый торрент убрать из клиента без удаления файлов.
2. **Отдельная серия** в нужной озвучке и качестве (получает бонус при выборе).
3. **Пак сезона.** Добавить на паузе → прочитать список файлов → приоритет 0 всем, кроме нужной серии → запустить.

В режиме «весь сезон после финала» ждём полный пак в нужной озвучке и качаем один раз.

## 5. Расписание

- Частота поиска: 15 мин / 1 ч / 2 ч / 6 ч / только ночью; ночное окно (по умолчанию 01:00–07:00).
- «Чаще, когда ждём серию»: в день прогноза озвучки — каждые 30 мин, пока не найдётся.
- Проверка обновлений знакомых паков — чаще основного поиска (раз в 30 мин), это одна дешёвая проверка хэша.
- Расписание скорости qBittorrent: сетка 7×24, состояния «полная / ограничено N МБ/с / пауза».

## 6. Обработка файлов

- После скачивания — пересборка mkv без перекодирования (mkvmerge): оставить озвучку из подписки + оригинал
  (варианты: только озвучку; ничего не трогать), опционально запасные озвучки из профиля.
- Флаги по умолчанию: основная аудиодорожка — озвучка из подписки; субтитры по умолчанию — форсированные
  (варианты: нет / форсированные / полные); оставлять субтитры: русские, английские.
- Вшивать внешние `.mka` / `.srt` из раздачи.
- Проверка ffprobe: разрешение, HDR, длительность (фильм вместо серии → удалить, в чёрный список, искать заново).
- Исходник остаётся в папке загрузок, пока идёт раздача; в библиотеке лежит пересобранная копия.
- Шаблон имени: `{Название} ({Год})/Season {С}/{Название} S{С}E{Е} [{Студия} {Качество}]`.

## 7. Уборка в qBittorrent

- Убирать торрент: сразу после импорта / после раздачи (N дней или рейтинг X) / никогда.
- Удалять файлы из папки загрузок вместе с торрентом.
- Убирать зависшие (нет сидов > суток) и заменённые раздачи.
- Чистить брошенные файлы в папке загрузок, не принадлежащие ни одному торренту.

## 8. Хранение

Уборка по расписанию (каждый день / раз в неделю / вручную) + «Запустить сейчас».
Правила:
- **Сезоны: последний + выходящий.** Когда выходящий сезон скачан целиком в нужной озвучке — предыдущий удаляется.
  Параметр: сколько вышедших сезонов хранить (по умолчанию 1). Завершённые сериалы: «не трогать» (по умолчанию) / «тоже чистить».
- **Старая копия после улучшения** (качество или приоритетная озвучка): удалять сразу / через 3 дня / при уборке.
- **Удалять через N дней после скачивания** — выключено, включается у отдельных сериалов.
- **Защита от переполнения:** предупредить при 90%, пауза загрузок при 97%.
- Исключения по сериалам («хранить все сезоны»).
- Первое срабатывание нового правила — список с галочками и итогом «освободится X ГБ», удаление только после подтверждения.
- Удаление сериала: «файлы и подписка» / «только файлы» / «только подписка».

## 9. Прогноз озвучки

- Dublyarr сам запоминает, когда впервые увидел серию N у студии X; дата эфира — из TMDB. Отсюда средняя задержка студии
  по сериалу и прогноз для календаря и главной.
- Показывать основание: «по 12 сериям» / «≈ по датам раздач» / «только паки» / «нет данных».

## 10. Фильмы

- Не качать экранки; ждать цифровой релиз (WEB-DL/BDRip); опционально улучшать до BDRemux; лимит размера.
- Перевод по приоритету: дубляж → многоголосый → оригинал + субтитры; ждать дубляж N дней после цифрового релиза;
  заменить на дубляж, когда выйдет.

## 11. Автоподписка на новые сезоны

- Когда TMDB объявил сезон сериала из библиотеки — подписаться с тем же профилем (сразу или спросить).
- Спин-оффы и продолжения — только уведомление.

## 12. Уведомления (Telegram)

События: скачана новая серия; загрузка застряла или раздача пропала; нужно подтверждение (сомнительная раздача, новая студия) —
с inline-кнопками; вышел оригинал, озвучки нет (выкл. по умолчанию); источник/трекер не отвечает больше часа.

## 13. Laya

Laya — открытая локальная модель решений (Convai Innovations, Apache-2.0). Не генерирует текст: выбор из вариантов,
да/нет, оценка — с откалиброванной уверенностью. Используем многоязычную модель `laya-multilingual`.

- Работает в том же контейнере: laya-serve — дочерний процесс Node на 127.0.0.1. В интерфейсе нет адреса и выбора модели,
  только статус («работает / недоступна», последний ответ) и кнопка «Проверить».
- Задачи: какая студия (выбор из словаря + «новая»); тот ли сериал (да/нет); нумерация аниме (выбор сезона/серии);
  финальная проверка выбранной раздачи перед загрузкой (да/нет, см. §3).
- Порог уверенности (по умолчанию 85%): выше — решение применяется, ниже — вопрос пользователю
  (Telegram-кнопки, «Требует внимания», словарь студий). Без ответа — ничего сомнительного не качать.
- Каждый ответ пользователя — размеченный пример (хранить в БД, включать в бэкап). Исправление ошибки вручную — тоже пример.
- Дообучение: автоматически ночью при 30+ новых примерах; применять новую версию только если на отложенных 20% не хуже;
  хранить 3 последние версии, откат в один клик.
- Обновления: у каждой версии отметка версии библиотеки и базовой модели. Несовместимо после обновления →
  временно базовая модель + переобучение на всех примерах в ближайшее ночное окно. Новая базовая модель — только по сравнению «не хуже».
- Если Laya недоступна — всё работает на словаре и правилах.

## 14. Вход

- Логин + пароль (argon2), затем TOTP (6 цифр), «запомнить устройство»
  и «не спрашивать код 30 дней на этом устройстве». Резервных кодов нет (решение владельца).
- Несколько учёток (2.3, решение владельца): первая — администратор; администратор создаёт пользователей и задаёт их права
  (подписки, ручной поиск и «Скачать», ответы на вопросы, загрузки, хранилище и удаление). Библиотека и подписки общие.
  У пользователя в настройках только «Уведомления» (свой чат Telegram и события) и «Безопасность» (без API).
- Сброс пароля — CLI внутри контейнера: `dublyarr reset-password [--user <логин>]`; потеря телефона — `--disable-2fa`.
- Не нарисовано, но нужно: «Настройки → Безопасность» (включение 2FA с QR-кодом, активные сеансы, выйти везде).

## 15. Экраны, которые ещё не нарисованы

- Поиск и тренды (поиск по TMDB, популярное, «скоро новые сезоны» по библиотеке) — нужен к фазе 1.
- Первый запуск (qBittorrent, источники, папки, профили) — к фазе 0.
- Карточка фильма — к фазе 3.
- Безопасность (см. §14).
- Мобильные экраны разделов настроек; вкладки «История», «Пропущенное», «Чёрный список» в «Активности»;
  панель уведомлений; вариант подписки для аниме.
