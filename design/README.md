# Макеты Dublyarr

Макеты сделаны в Claude (Design canvas). Каждый экран — файл `screens/<Имя>.dc.html`.
Это не готовый HTML для браузера: без рантайма холста файлы не отрисуются. Читай их как спецификацию.

## Как читать `.dc.html`

- Разметка внутри `<x-dc>` — настоящая вёрстка с inline-стилями: размеры, отступы, цвета, шрифты — точные.
- `{{name}}` — подстановка значения из `renderVals()` в `<script type="text/x-dc">` внизу файла.
- `<sc-for list="{{items}}" as="item">` — повтор блока для каждого элемента массива.
- `<sc-if value="{{flag}}">` — условный блок.
- `<dc-import name="Sidebar" active="today">` — вставка компонента из `Sidebar.dc.html` с параметром.
- Данные в `renderVals()` — пример реального содержимого экрана. Отсюда же видно, какие поля нужны от API.
- `<a href="Other.dc.html">` — переход между экранами.
- `canvas.json` — раскладка холста: названия экранов (`title`) и размеры.

## Дизайн-токены

Шрифты (Google Fonts):
- Заголовки — **Unbounded** 500/600/700
- Текст — **Onest** 400/500/600/700
- Цифры, коды, имена файлов, релизы — **JetBrains Mono** 400/500

Цвета (тёмная тема, светлой нет):
| Токен | Значение | Где |
|---|---|---|
| bg | `#121110` | фон страницы |
| surface | `#1B1A18` | карточки, поля |
| surface-2 | `#242220` | вложенные блоки, неактивные плашки |
| sidebar | `#171614` | боковая и нижняя навигация |
| line | `#2E2B28` | рамки |
| line-soft | `#242220` | разделители строк |
| line-strong | `#3A3632` | рамки кнопок второго уровня |
| text | `#F3EFE8` | основной текст |
| text-2 | `#D9D3C9` | вторичный текст |
| muted | `#A39C92` | подписи |
| faint | `#8A847B` | мелкие подписи |
| accent | `#F0A442` | акцент, «ждём озвучку», прогноз, основная кнопка (текст на ней `#1A1206`) |
| progress | `#7FB2FF` | загрузки, «качается» |
| danger | `#FF8A7A` | ошибки, «требует внимания»; фон карточки `#1F1916`, рамка `#4A2F28` |
| destructive | `#E5654F` | кнопка удаления |

Радиусы: 8–12 px у кнопок и плашек, 14–18 px у карточек, 22–24 px у модалок и шторок.
Цели нажатия ≥ 44 px. Прогноз озвучки всегда — пунктирная янтарная рамка; «скачано» — светлая заливка; «оригинал» — серая рамка.

Постеры в макетах — цветные заглушки; в продукте — картинки TMDB.
